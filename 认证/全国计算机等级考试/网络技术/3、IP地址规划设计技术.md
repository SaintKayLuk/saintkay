## IP地址规划设计技术


A类地址：1.0.0.0 ~ 127.255.255.255
B类地址：128.0.0.0 ~ 191.255.255.255
C类地址：192.0.0.0 ~ 223.255.255.255
D类地址：224.0.0.0 ~ 239.255.255.255
E类地址：240.0.0.0 ~ 247.255.255.255


* 专用地址
  * A类：10.0.0.0 ~ 10.255.255.255
  * B类：172.16.0.0 ~ 172.31.255.255
  * C类：192.168.0.0 ~ 192.168.255.255

网络地址+主机地址
例如 11111111.11111111.10101010.10101010/16
则网络位是 11111111.11111111 主机位是10101010.10101010

第一个是和最后一个不能用，一个是自己，一个是广播用

网络地址：网络位不变，主机位全为0，前面不变，后面全为0
直接广播地址：网络位不变，主机位全为1，前面不变，后面全为1
主机号：网络位为0，主机位不变，前面全变0，后面不变
第一个可用地址：网络地址的后一个，前面不变，后面全为0，最后一个是1


### 掩码长度

| 二进制    | 十进制 | 掩码长度 | 计算技巧       |
|-----------|--------|----------|----------------|
| 1000 0000 | 128    | 1        | 2^7=128        |
| 1100 0000 | 192    | 2        | 2^7+2^6=128+64 |
| 1110 0000 | 224    | 3        | 128+64+32      |
| 1111 0000 | 240    | 4        | 128+..+16      |
| 1111 1000 | 248    | 5        | 128+..+8       |
| 1111 1100 | 252    | 6        | 128+..+4       |
| 1111 1110 | 254    | 7        | 128+..+2       |
| 1111 1111 | 255    | 8        | 128+..+1       |

掩码长度是指一个8位里面的，最大32，指255.255.255.255，如果是16则是 255.255.0.0 依次类推

### IPv6

* IPv6
  * 单播地址
  * 组播地址
  * 多播地址
  * 特殊地址


ipv4是4个8位，用 **.**区分， 转为10进制，最大255.255.255.255
ipv6是8个16位，


```
ipv4是这种，再从二进制转为10进制表示，取值 123456789
11110000.11110000.11110000.11110000

ipv6是这种，再从二进制转为16进制表示，取值 123456789ABCDEF
1111111100000000:1111111100000000:1111111100000000:1111111100000000:1111111100000000:1111111100000000:1111111100000000:1111111100000000
```


##### 零压缩法

压缩每一位前面的0

例如
```
21DA:0000:0000:0000:02AA:FE08:000F:9C5A

    ↓ 简化为 ↓

21DA:0:0:0:2AA:FE08:F:9C5A
```

##### 双冒号表示法

连续的位段都是0则可以表示为 ::

例如
```
21DA:0:0:0:2AA:FE08:F:9C5A

    ↓ 简化为 ↓

21DA::2AA:FE08:F:9C5A
```

**双冒号只能出现一次**
例如：
```
21DA:0:0:0:2AA:0:0:9C5A

    ↓ 简化为 ↓

21DA::2AA:0:0:9C5A
    或者
21DA:0:0:0:2AA::9C5A   
```
