#### 其他



1、环回接口（loopback）作为一台路由器的管理地址，网络管理员可以为其分配一个IP地址作为管理地址，其掩码应为255.255.255.255 。

2、Flash存储器即闪存，用于存储路由器当前使用的操作系统映像文件和微代码。

NVRAM即非易失性随机存储器，主要用于存储启动配置文件或备份配置文件。

RAM即随机存储器，它是一种可读可写存储器，主要用于描述特别长的情况。

ROM即只读内存，主要用于永久保存路由器的开机诊断程序、引导程序和操作系统软件。

3、Global Configuration 是全局配置模式，输入configure terminal 命令。

Privileged EXEC 是特权模式，需要在用户模式（User EXEC）模式下输入enable命令。

Setup是设置模式，进入一台刚出厂的没有任何配置的路由器。

RXBOOT模式是路由器的维护模式，在密码丢失时，可以进入该模式，以恢复密码。

3）使用**telnet**远程登录到**路由器**上配置路由器

4）使用**TFTP**服务，以**拷贝**配置文件、**修改配置文件**的形式配置路由器

5）通过网络管理协议**SNMP修改路由器配置文件**的方式，从而对路由器进行配置。

4、RIP路由协议是在Router（config-router）#模式下进行配置。

5、路由器的路由表项第一列是路由源码，C表示直连，S表示静态路由，O使用OSPF协议，E使用EGP外部网关协议获得路由信息；第二列为目的网络地址和掩码；第三列是目的端口或下一跳路由器地址。另外还有缺省路由器表项，目的地址为0.0.0.0/0 。

6、从NVRAM加载配置信息命令为：configure memory

​ 将路由器配置保存在NVRAM中命令为：write memory

7、执行路由器的ip route 命令必须进入的工作模式是全局配置模式。

8、、管理距离用于衡量路由表中给定的信息源的“可信度”。管理距离的值越小，路由信息源的可信度越高。

路由协议	管理距离值	可信度
直接路由（connected）	0	0
静态路由（static）	1	1
GRP路由	100	100
中间系统到中间系统的路由选择协议（IS-IS）	115	115
开放式最短路径优先协议（OSPF）	110	110
RIP路由	120	120
路由器在转发数据包时，会选择路由信息源是**直接路由（connected）**的路径转发数据包。

9、在显示路由器的配置信息时，路由器必须进入的工作模式是特权模式。

用户模式：它是个只读模式，在该模式下，用户只可以对路由器做一些简单的操作，有限度的查看路由器的相关信息，但是不能对路由器的配置做任何修改。

特权模式：在用户模式下输入“enable”命令和超级用户密码，就可以进入特权模式。特权模式可以管理系统时钟、进行错误检测、查看和保存配置文件、清除闪存、处理并完成路由器的冷启动等操作。

设置模式：通过Console端口进入一个刚出厂的没有任何配置的路由器时，控制台就会进入设置模式。

虚拟终端配置模式：在全局模式下，通过line vty命令进入虚拟终端配置模式。

10、OSPF区域的数字标识称为区域ID，区域ID是一个32位无符号数，数值范围是0～4294967295，区域ID为0的另一种表示形式是0.0.0.0 。如果区域ID为0或0.0.0.0 时，则表示骨干区域。

11、OSPF可以换分区域，路由更新信息在同一个区域内传播。区域边界路由器负责接收从其他区域来的信息。

12、路由器配置命令：

​ 保存配置信息：write erase

​ 删除配置信息：write erase

13、缺省路由既可以由网络管理员手工设置，也可以通过某些动态路由协议生成，由“O*E1 0.0.0.0/0 [110/21] via 162.105.252.189，2w6d，TenGigabitEthernet1/15”语句可知，此处是由OSPF协议生成的，而非管理员手工设置。

14、在Cisco路由器上配置DHCP服务器时首先配置IP地址池（Pool）的名称，并由此进入DHCP Pool配置模式。在DHCP Pool配置模式下，配置IP地址池的子网地址和子网掩码、缺省网关、域名和域名服务器的IP地址、IP地址的租用时间和取消地址冲突记录日志等参数。

1）配置IP地址池的名称，并进入DHCP Pool配置模式。
	在全剧配置模式下——ip dhcp pool <地址池的名称>

2）配置IP地址池的子网地址和子网掩码。
	在DHCP Pool配置模式——network<网络地址><子网掩码>

3)配置不参与动态分配的IP地址（除外地址）。
	在全局配置模式下——ip dhcp excluded-address<低地址><高地址>

4)配置IP地址池的缺省网关。
	在DHCP Pool配置模式下——default-router<网关地址>

5）配置IP地址池的域名系统。
	a.配置IP地址池的域名——domain-name<域名>
	b.配置IP地址池的域名服务器的IP地址——dns-server<域名服务器的IP地址>

6）配置IP地址池的地址租用时间。
	在DHCP Pool配置模式下——lease{天 [时/分] ｜无限 }

7）配置取消地址冲突记录日志。
	在全局模式下——no ip dhcp conflict logging
