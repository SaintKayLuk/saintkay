## 中小型网络系统总体规划与设计方法



#### 网络需求调研与系统设计的基本原则
1. 从充分调查入手
2. 在调查、分析的基础上，在充分考虑需求与约束
3. 运用系统的观念，完成网络工程技术方案的规划和设计
4. 根据工程时间的要求，将网络系统组建的任务安装设计、论证、实施、验收、用户培训、维护的不同阶段进行安排
5. 强调各阶段文档资料的完整性与规范性


#### 路由器

路由器一般根据路由器背板交换能力来划分
1. 大于40Gbps的为高端路由器
2. 小于40Gbps的为中低端路由器

高端路由器一般用于核心层，企业路由器一般用于汇聚层，低端路由器用于接入层


* 高端路由器：
  * 无故障连续时间(MTBF)**大于10万小时**
  * 系统故障恢复时间(MTBR)**小于30分钟**
  * 自动保护切换功能，主备切换**小于50毫秒**
  * SDH和ATM接口自动保护切换功能，切换时间小于50毫秒
  * 主要部件热插拔冗余备份
  * 系统内部不存在单点故障

#### 路由器的关键技术指标
1. 吞吐量
2. 背板能力
3. 丢包率
4. 延时与延时抖动
5. 突发处理能力
6. 路由表容量
7. 服务质量
8. 网管能力
9. 可靠性与可用性



#### 服务器性能


磁盘存储能力，两个方面：**存储容量**，**I/O速度**
* 参数
  * 主轴转速
  * 内部传输率
  * 单碟容量
  * 平均巡道时间
  * 缓存

```
                  MTBF
系统高可用性 = ————————————
                MTBF + MTBR
```
MTBF：平均无故障时间，相当于**可靠性**
MTBR：平均维修时间，相当于**可维护性**


| 可用性   | 全年停机小时数 | 全年停机时间 |
| -------- | -------------- | ------------ |
| 99.9%    | 8.76小时       | ≤8.76小时    |
| 99.99%   | 0.876小时      | ≤52.6分钟    |
| 99.999%  | 0.0876小时     | ≤5.26分钟    |
| 99.9999% | 0.00876小时    | ≤31.53秒     |






上联带宽和下联带宽比一般为 **1:20**
