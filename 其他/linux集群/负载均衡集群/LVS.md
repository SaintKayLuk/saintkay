## Linux Virtual Server
Linxu虚拟服务器

## 工作模式


* NAT模式
* TUN模式
* DR模式


### NAT模式

客户端访问lvs，lvs访问真实服务器，通过DNAT技术，转换目标ip端口，真实服务器返回给lvs，lvs通过SNAT转换源IP端口，返回给客户端

数据包传递过程，客户端 --> lvs --> RS(真实服务器) --> lvs --> 客户端
```
                    S:10.10.10.2      DNAT          S:10.10.10.2
                    D:10.10.10.3                    D:192.168.1.0/24
client(10.10.10.2)  ------------> LVS(10.10.10.3)   ----------------> RS(192.168.1.0/24)
                    <------------                   <---------------- 
                    S:10.10.10.3      SNAT          S:192.168.1.0/24
                    D:10.10.10.2                    D:10.10.10.2
```


* 集群节点除域同一网络环境中
* 真实服务器必须将网官指向负载调度器
* 真实服务器ip通常是私有ip，仅用于各个集群节点通信
* 负载调度器必须位于真实服务器和客户端之间，充当网关
* 支持端口映射
  * DNAT 和 SNAT 也能支持端口转换
* 负载调度器必须是linux系统，真实服务器随意
* 进出数据报文都要经过负载调度器，压力较大



### TUN模式

数据包传递过程，客户端 --> lvs --> RS --> 客户端

```
                    S:11.22.33.44                   S:22.33.44.55(11.22.33.44)
                    D:22.33.44.55                   D:33.44.55.66(22.33.44.55)  RS(33.44.55.65)
client(11.22.33.44) ------------> LVS(22.33.44.55)  ------------------------->  RS(33.44.55.66)
                    <---------------------------------------------------------  RS(33.44.55.67)
                                          S:22.33.44.55
                                          D:11.22.33.44
```


lvs 和 RS 并不在同一局域网中，都在公网，客户端先请求lvs，lvs对源地址和目标地址包装一层，把源地址改为自己，目标地址改为 RS 的地址，RS接受到数据包后，会拆包，然后再根据原源地址和目标地址，返回数据包



* 集群所有节点必须直接或者间接拥有公网地址
* 真实服务器必须将网关指向真实网关处
* 不支持端口映射
* DS 和 RS 必须开启隧道功能
* 入站由 DS 完成，出站由 RS 完成
* 负载调度器必须是Linux系统，真实服务器随意
* 压力较大


### DR模式
数据包传递过程，客户端 --> lvs --> RS --> 客户端
```
                      S:192.168.1.200           DMAC        S:192.168.1.200
                      D:192.168.1.100:80                    D:192.168.1.100:80  RS(192.168.1.11,192.168.1.100,MAC1)
client(192.168.1.200) -----------------> LVS(192.168.1.100) ----------------->  RS(192.168.1.12,192.168.1.100,MAC2) 
                      <-------------------------------------------------------  RS(192.168.1.13,192.168.1.100,MAC3)
                                          直接返回给客户端                                                           
                                          
```

lvs 和 RS 在同一局域网中， 客户端访问 lvs ，lvs 通过DMAC修改MAC地址为真实服务器MAC地址，真实服务器有自己的ip和lvs的ip，但lvs的ip只有自己知道，接收到经过lvs处理过的数据请求，再处理返回给客户端



* 集群节点处于同一广播域中
* 真实服务器将网关之上真实路由器
* 负载调度器只负责处理入站请求
* 不支持端口映射
* 负载调度器必须是Linxu，真实服务器最好是linux
