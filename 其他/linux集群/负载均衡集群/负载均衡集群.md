## 分类

* 软
  * LVS
  * nginx
  * haproxy
* 硬
  * F5

二层负载：F5等硬负载服务器作用于数据链路层
四层负载：LVS作用于传输层
七层负载：nginx作用于应用层




## 四层负载

以LVS为例，数据不经过LVS，LVS只是修改报文得源地址和目标地址，一个请求一个连接
```
                    S:10.10.10.2                    S:10.10.10.2
                    D:10.10.10.3                    D:192.168.1.0/24
client(10.10.10.2)  ------------> LVS(10.10.10.3)   ----------------> server(192.168.1.0/24)
                    <------------                   <---------------- 
                    S:10.10.10.3                    S:192.168.1.0/24
                    D:10.10.10.2                    D:10.10.10.2
```

## 七层负载

以nginx为例，数据经过nginx转发，一个请求，客户端请求nginx，nginx请求 提供服务的服务器
```
                    S:192.168.1.2:                      S:192.168.1.3
                    D:192.168.1.3:80                    D:192.168.1.0/24
client(192.168.1.2) ---------------> nginx(192.168.1.3) --------------->  server(192.168.1.0/24)
                    <---------------                    <---------------
                    S:192.168.1.3:80                    S:192.168.1.0/24                                 
                    D:192.168.1.2                       D:192.168.1.3
```
