## 安装域控服务器

sqlserver的高可用 Always On 依赖于域控服务器



#### 安装 域控AD 和 DNS
1. 设置静态ip，dns
2. 右键键“此电脑” → “属性” → “更改设置” → 改主机名为 DC，重启
3. 打开“服务器管理器”，点左上角“管理” → “添加角色和功能”
   1. 安装向导中依次选择：
   2. 安装类型：基于角色或功能的安装
   3. 服务器选择：选择本地服务器
   4. 角色选择：勾选 ✅
   5. 勾选 ”Active Directory 域服务”
   6. 勾选 “DNS 服务器”
   7. 一路“下一步” → “安装”

#### 升级为域控服务器
1. 安装完 AD DS 后，服务器管理器右上角会出现黄色感叹号，点击“将此服务器提升为域控制器”。
   1. 提升配置填写：
   2. 选择：新建林
   3. 根域名：比如 u9c.com
   4. 设置 DSRM 密码（目录服务恢复模式密码）
   5. 点击“安装”并重启

## sqlserver服务器加入域

1. 先修改主机名，修改静态ip，dns指向域控的服务器ip，并重启
2. 加入域，属于域控的用户名密码


**问题：无法与域"XX.COM"的 Active Directory 域控制器(AD DC)连接**
1. DNS解析不正确，找不到 域名的ip
2. 设置网络，手动设置dns服务器为域名服务器的ip

**问题：尝试加入域时，该计算机的 SID 与域中已有计算机的 SID 相同**
1. . 打开 C:\Windows\System32\Sysprep 文件夹
2. 运行 sysprep.exe
   1. 系统清理操作（System Cleanup Action）：进入系统全新体验（OOBE）
   2. 勾选：通用（Generalize）
   3. 关机选项：重新启动
3. 重启之后会重新设置密码
