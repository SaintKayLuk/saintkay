## sqlserver备份
先安装sqlcmd

```sh
#!/bin/bash

# 设置变量
DB_NAME="MyDatabase"
BACKUP_PATH="/path/${DB_NAME}_$(date +%Y%m%d).bak"
SQL_SERVER_IP="x.x.x.x"
SA_PASSWORD="YourStrong@Passw0rd"


# 备份命令
sqlcmd -S $SQL_SERVER_IP \
    -U SA \
    -P $SA_PASSWORD \
    -Q "BACKUP DATABASE [$DB_NAME] TO DISK = N'$BACKUP_PATH' WITH FORMAT, MEDIANAME = 'MyDatabaseBackup', NAME = 'Full Backup of $DB_NAME';"

# 打印结果
echo "Database $DB_NAME backed up to $BACKUP_PATH"
```

**注意：** 不管sqlcmd在哪里执行，备份的 BACKUP_PATH 路径都是 sqlserver 所在的机子上，需要手动拷贝到其他地方

## sqlserver恢复

先安装sqlcmd

```sh
#!/bin/bash

# 设置变量
DB_NAME="MyDatabase"
BACKUP_PATH="/path/$BACKUP_FILE"                #备份文件路径
SQL_SERVER_IP="x.x.x.x"                         # SQL Server 实例的 IP 地址
SA_PASSWORD="YourStrong!Passw0rd"

# 恢复命令
sqlcmd -S $SQL_SERVER_IP \
    -U SA \
    -P $SA_PASSWORD \
    -Q "RESTORE DATABASE [$DB_NAME] FROM DISK = N'$BACKUP_PATH' WITH FILE = 1, NOUNLOAD, REPLACE, STATS = 10;"

# 打印结果
echo "Database $DB_NAME restored from $BACKUP_PATH"
```
