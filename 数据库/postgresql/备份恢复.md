## 备份

切换到 postgres 用户来执行，或者用 postgres 用户来执行



例：试用 postgres 来执行，并通过 gzip 压缩成带日期的压缩文件
```sh
su - postgres -c "pg_dump xxx | gzip > /backup/xxx_$(date +%F).sql.gz"
```

放到crontab 中，需要对 %F 转义一下，否则 % 会作为换行符，并且用 postgres 用户执行

例：每天凌晨2点执行备份，备份名为 xxx_2025-01-01.sql.gz
```sh
sudo -u postgres crontab -e
```

```
0 2 * * * /bin/bash -c '/usr/bin/pg_dump shmcplm 2>> /data/backup/error.log | gzip > /data/backup/shmcplm_$(date +\%F).sql.gz'
```
