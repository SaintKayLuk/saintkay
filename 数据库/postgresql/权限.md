# 权限



navicat 登录使用md5验证

postgresql.conf 配置文件里修改
```conf
password_encryption = md5
```



pg_hba.conf 文件里设置为
```conf
host    all             all             0.0.0.0/0            	md5
```


重启






## 批量修改表的所有者

在对应的库下执行
```sql
DO
$$
DECLARE
    tbl RECORD;
BEGIN
    FOR tbl IN
        SELECT tablename FROM pg_tables WHERE schemaname = 'public'
    LOOP
        EXECUTE format('ALTER TABLE %I OWNER TO wecharmer', tbl.tablename);
    END LOOP;
END;
$$;
```

验证下
```sql
SELECT tablename, tableowner
FROM pg_tables
WHERE schemaname = 'public';
```
