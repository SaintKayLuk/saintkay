# 权限



navicat 登录使用md5验证

postgresql.conf 配置文件里修改
```conf
password_encryption = md5
```

pg_hba.conf 文件里设置为
```conf
host    all             all             0.0.0.0/0            	md5
```

修改完之后重新加载
```sh
sudo systemctl reload postgresql
```


## 配置文件详解

例
```conf
host    database        all             0.0.0.0/0               scram-sha-256
```

* 第一列：连接类型
  * local：只允许本地连接，例如postgres可以通过本地连接
  * host：匹配使用 TCP/IP 进行连接。包括SSL或非SSL以及GSSAPI加密或非GSSAPI加密
  * hostssl：匹配使用ssl加密连接
  * hostnossl：配件使用非ssl加密连接
  * hostgssenc：匹配使用GSSAPI加密建立的连接
  * hostnogssenc：匹配未使用GSSAPI加密的连接

* 第二列：database，匹配哪些数据库名称
  * database：指定某个数据库
  * all：则表示所有数据库
  * replication：流复制连接

* 第三列：用户
  * user：指定用户名
  * all：代表所有用户

* 第四列：address，匹配的客户端计算机地址
  * all：匹配所有地址
  * 172.20.143.89/32：匹配单个主机
  * 172.20.143.0/24：匹配一个网段

* 第五列：auth-method，身份验证方法
  * trust: 无条件允许连接
  * reject：无条件拒绝连接
  * scram-sha-256：执行 SCRAM-SHA-256 身份验证以验证用户密码，**默认建议使用**
  * md5：执行 SCRAM-SHA-256 或 MD5 身份验证以验证用户密码
  * peer：检查系统用户名和数据库用户名身份匹配，此方法仅适用于本地连接，例如 postgres 本地连接












## 修改数据库权限


如果要改某个数据库的用户，则需要同时换数据库 owner + 换schema owner + 换表 owner + 换普通视图 owner + 物化视图 owner
默认public schema 的权限是 pg_database_owner，所有只要换数据库和表的就行

**更改数据库owner**
```sql
ALTER DATABASE xxx OWNER TO xxx;
```

**批量修改表的所有者**
在对应的库下执行
```sql
DO $$
DECLARE r RECORD;
BEGIN
    FOR r IN SELECT tablename FROM pg_tables WHERE schemaname='public' LOOP
        EXECUTE 'ALTER TABLE public.' || quote_ident(r.tablename) || ' OWNER TO xxx';
    END LOOP;
END$$;
```

**同时改 sequences owner（如果有自增）**
在对应的库下执行
```sql
DO $$
DECLARE r RECORD;
BEGIN
    FOR r IN SELECT sequencename FROM pg_sequences WHERE schemaname='public' LOOP
        EXECUTE 'ALTER SEQUENCE public.' || quote_ident(r.sequencename) || ' OWNER TO xxx';
    END LOOP;
END$$;
```

验证下
```sql
SELECT tablename, tableowner
FROM pg_tables
WHERE schemaname = 'public';
```




**一次性查出所有对象（表+视图）的所有者**
在对应的库下执行
```sql
SELECT 
    n.nspname AS "模式",
    c.relname AS "对象名",
    CASE c.relkind
        WHEN 'r' THEN '普通表'
        WHEN 'v' THEN '普通视图'
        WHEN 'm' THEN '物化视图'
        WHEN 'S' THEN '序列'
        ELSE c.relkind::text
    END AS "类型",
    r.rolname AS "所有者"
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
JOIN pg_roles r ON r.oid = c.relowner
WHERE n.nspname NOT IN ('pg_catalog', 'information_schema')
  AND c.relkind IN ('r', 'v', 'm', 'S') -- 这里控制查什么：r=表, v=视图, m=物化视图, S=序列
  AND r.rolname != 'user' -- 筛选不是 user 的
ORDER BY "类型", "模式", "对象名";
```


**批量修改视图的所有者**
先生成sql
```sql
-- 生产 修改视图的 sql，把所有者为 user 的 视图改为 所有者为 newUser
SELECT 
    'ALTER VIEW ' || schemaname || '.' || viewname || ' OWNER TO newUser;'
FROM pg_views
WHERE schemaname NOT IN ('pg_catalog', 'information_schema')
  AND viewowner != 'user';
```
