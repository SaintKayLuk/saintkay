# postgresql


命令行进去 数据库
```sh
sudo -u postgres psql
```


#### 创建用户
```sql 
-- 创建普通用户（带密码）
CREATE USER myuser WITH PASSWORD 'mypassword';

-- 创建超级用户
CREATE USER myuser WITH SUPERUSER PASSWORD 'mypassword';

-- 创建可创建数据库的用户
CREATE USER myuser WITH CREATEDB PASSWORD 'mypassword';

-- 创建复制用户（用于流复制）
CREATE ROLE replicator WITH REPLICATION LOGIN PASSWORD 'ReplPass123';
```


#### 创建数据库
```sql
CREATE DATABASE mydb 
WITH OWNER = myuser 
TEMPLATE = template0 
ENCODING = 'UTF8' 
LC_COLLATE = 'en_US.UTF-8' 
LC_CTYPE = 'en_US.UTF-8';
```
