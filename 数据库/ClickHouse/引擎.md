## 表引擎

不同的表引擎决定了：
* 数据的存储方式和位置、写入位置以及读取位置。
* 支持哪些查询，以及如何支持。
* 并发数据访问。
* 使用索引（如果存在）。
* 是否可以执行多线程请求。
* 数据复制参数。

### MergeTree

#### MergeTree

创建MergeTree引擎表时，必须指定ORDER BY
主键字段必须在排序字段中，并且，不能跳过多个排序字段取后面的字段作为主键
例如：ORDER BY (id1,id2) ，则主键可以设置为id1，或者id1和id2都设置为主键，也可以不设置主键，但是不能只设置id2为主键
```sql
CREATE TABLE [IF NOT EXISTS] [db.]table_name [ON CLUSTER cluster]
(
    name1 [type1] [DEFAULT|MATERIALIZED|ALIAS expr1] [TTL expr1],
    name2 [type2] [DEFAULT|MATERIALIZED|ALIAS expr2] [TTL expr2],
) ENGINE = MergeTree()
ORDER BY expr
[PARTITION BY expr]
[PRIMARY KEY expr]
```


* 分区，非必须
* 主键，非必须
* 排序，必须
* TTL，过期时间





#### ReplacingMergeTree

MergeTree的一个变种，比MergeTree多了一个去重功能，只能保证最终去重

```sql
CREATE TABLE 
...
) ENGINE = ReplacingMergeTree([ver])
```
创建ReplacingMergeTree引擎表时，可以指定带版本号的列(ver)，例如 UInt，Date，当合并时，有相同的order by 字段，则根据版本字段，UInt则留最大的，Date取最新的，如果版本号字段也相同，则留最后插入的数据

* 根据order by 字段作为条件去去重
* 不能跨分区去重
* 同一批插入的时候会去重一次 或 合并分区的时候去重
