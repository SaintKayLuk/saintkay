
## 触发器
SQL触发器是存储在数据库目录中的一组SQL语句。每当与表相关联的事件发生时，即会执行或触发SQL触发器，例如插入，更新或删除



每个表最多能设置6种触发器

| 触发器类型    | 作用                           |
|---------------|------------------------------|
| BEFORE INSERT | 在数据插入表之前被激活触发器   |
| AFTER INSERT  | 在将数据插入表之后激活触发器   |
| BEFORE UPDATE | 在表中的数据更新之前激活触发器 |
| AFTER UPDATE  | 从表中删除数据之后激活触发器   |
| BEFORE DELETE | 在从表中删除数据之前激活触发器 |
| AFTER DELETE  | 从表中删除数据之后激活触发器   |


常见触发器命名
```
[before|after]_tablename_[insert|update|delete]

例：在表user更新之后更新，即AFTER UPDATE
after_user_update
```

* 创建触发器
```sql
DELIMITER $$
CREATE TRIGGER trigger_name trigger_time trigger_event 
ON table_name 
FOR EACH ROW
BEGIN
...
END$$
DELIMITER ;
-- 因为在BEGIN和END之间是执行语句，而mysql以分号(;)代表一个sql的结束，所以通过DELIMITER $$ 替代;的作用。即END$$才是整个sql语句的结束，最后再通过DELIMITER ; 改为;为结束语




例：为user111表创建触发器，在user111表中插入数据之后执行BEGIN和END之间的语句
CREATE TRIGGER after_user111_insert AFTER INSERT 
ON user111
FOR EACH ROW
BEGIN
...
END;
```



#### 多重触发器
5.7.2之后可以为同一事件创建多个触发器，此之前同一事件(例如AFTER UPDATE)只能创建一个触发器

如果表中有相同事件有多个触发器，MySQL将按照创建的顺序调用触发器。
要更改触发器的顺序，需要在FOR EACH ROW子句之后指定FOLLOWS或PRECEDES 

* FOLLOWS   新触发器在现有触发器之后激活
* PRECEDES  新触发器在现有触发器之前激活


触发器按顺序执行
```sql
DELIMITER $$
CREATE TRIGGER trigger_name [ BEFORE | AFTER ] [ INSERT | UPDATE | DELETE ] ON table_name FOR EACH ROW
[ FOLLOWS | PRECEDES ] existing_trigger_name 
BEGIN
...
END $$
DELIMITER;

```

##### 通过information_schema表查询触发器

* 查询某个数据库的触发器
```sql
SELECT 
    * 
FROM 
    information_schema.TRIGGERS 
WHERE 
    trigger_schema = 'database_name' 
```

* 查询某个触发器
```sql
SELECT 
    * 
FROM 
    information_schema.TRIGGERS 
WHERE 
    trigger_schema = 'database_name' 
    AND trigger_name = 'trigger_name';
```

##### 通过SHOW TRIGGERS 查询触发器

```sql
--查看当前数据库所有触发器
SHOW TRIGGERS;
--查看指定数据库的所有触发器
SHOW TRIGGERS [FROM|IN] database_name;
--查看某张表的触发器
SHOW TRIGGERS FROM database_name WHERE `table` = 'table_name';
```

##### 删除触发器
```sql
DROP TRIGGER table_name.trigger_name;
```
如果要修改触发器，则先删除原有触发器，再创建一个新的

例：删除数据库test的所有触发器
```sql
SELECT CONCAT('DROP TRIGGER ','test.',TRIGGER_NAME,';') FROM information_schema.TRIGGERS WHERE TRIGGER_SCHEMA = 'test' 
```
