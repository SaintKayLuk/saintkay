## 备份数据

```sh
mysqldump [选项] > file_name
    --all-databases         #备份所有数据库
    --databases db1 db2     #备份db1，db2数据库
    --host,-h               #指定数据库地址
    -P(大写)                #指定端口
    -u                      #用户名
    -p                      #密码
    --quick,-q              #一次拉取一行，默认拉取整张表到内存中
    --single-transaction    #不锁表，和 (默认--lock-tables)互斥


#--databases后面跟的都是数据库名，如果不加--databases则默认第一个为数据库名称，后面的为表名称
#使用 --all-databases 或者 --databases 会在备份文件中加入 CREATE DATABASE 和 USE 声明，确保恢复数据时候，在数据库不存在的时候创建数据库

```



例：备份db1数据库为dump.sql，可以省略--databases ，但是没有数据库命令，在恢复的时候必须指定数据库，建议加上--databases
```
mysqldump db1 > dump.sql
mysqldump --databases db1 > dump.sql
```



## 还原备份

通过--all-databases 或 --databases 备份的文件可以直接还原，不需要指定数据库
```sh
#将dump.sql备份还原到db1数据库 
#shell中
shell> mysql < dump.sql
shell> mysql db1 < dump.sql 
#mysql中
mysql> source dump.sql

msyql> CREATE DATABASE IF NOT EXISTS db1
mysql> USE db1;
mysql> source dump.sql
```
