# 排序规则


* 大小写敏感与否
  * ci：表示 case-insensitive，即不区分大小写。比如，a 和 A 会被视为相同。
  * cs：表示 case-sensitive，即区分大小写。比如，a 和 A 会被视为不同的字符。
  * ai：表示 accent-insensitive，即不区分重音符号。比如，é 和 e 被视为相同的字符。
  * as：表示 accent-sensitive，即区分重音符号。比如，é 和 e 会被视为不同的字符。

| 排序规则           | 适用场景                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------- |
| utf8mb4_unicode_ci | 基于较旧的 Unicode 标准，兼容性好，常用于较旧的 MySQL 版本或更简单的场景。      |
| utf8mb4_0900_ai_ci | 基于最新的 Unicode 9.0 标准， 不区分大小写、不区分重音符号，适用于大多数国际化场景，常用于默认配置。 |
|                    |                                                                                                      |
