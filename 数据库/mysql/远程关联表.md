### FEDERATED 引擎支持

建立远程关联表的数据库要支持FEDERATED引擎，比如A数据库关联B数据包，则A数据库要支持FEDERATED引擎。
查看是否支持FEDERATED 引擎
```sql
show engines;
```
| Engine    | Support | Comment                        | Transactions | XA | Savepoints |
|-----------|---------|--------------------------------|--------------|----|------------|
| FEDERATED | YES     | Federated MySQL storage engine | NO           | NO | NO         |

如果不支持 FEDERATED，则需要在mysql配置文件中添加
```sh
[mysqld]
federated
```

### 建立源表

和建立普通表一样,例如
```sql
CREATE TABLE test_table
(
...
)
DEFAULT CHARSET = latin1
```

### 建立远程表

表结构要和远程表一致，另外要指定引擎和远程地址
```sql
CREATE TABLE test_table
(
...
)
ENGINE = FEDERATED
DEFAULT CHARSET = latin1
CONNECTION='mysql://user:password@remote_ip:port/test_databases/test_table';
```

### 其他

例如A数据库的test_table表关联B数据库的test_table表
* 则在A数据库操作数据相当于在B数据库操作
* 删除A数据库test_table表，不会影响B数据的，即 B 数据库是源
* 删除 B 数据库的test_table表，会使 A 数据库的 test_table表失效，
