## 安装前提

* BE 节点 CPU 需支持 AVX2 指令集
* CentOS 7.x 或以上
* FE节点 jdk 1.8 或以上
* 关闭交换区，消除交换内存到虚拟内存时对性能的扰动
```sh
echo 0 | sudo tee /proc/sys/vm/swappiness
```
* 使用 Overcommit
```sh
echo 1 | sudo tee /proc/sys/vm/overcommit_memory
```

FE 节点建议配置 8 核 或以上 CPU，16GB 或以上内存
BE 节点建议配置 16 核 或以上 CPU，64GB 或以上内存

## StarRocks
* StarRocks
  * FE节点：前端节点，负责管理元数据，管理客户端连接，进行查询规划，查询调度等工作。
  * BE节点：数据节点

## backends(BE)


1. 下载 StarRocks-2.3.0.tar.gz

```sh
#解压
tar -zxf StarRocks-2.3.0.tar.gz
#切换be目录
cd StarRocks-2.3.0/fe
#添加数据目录
mkdir -p storage
```

2. 修改配置文件
```
conf/be.conf
```

3. 启动
```
bin/start_be.sh --daemon
```

BE集群， 多起几个BE，用FE添加就可以作为集群

## frontends(FE)

下载 StarRocks-2.3.0.tar.gz
下载 jdk-8u341-linux-x64.tar.gz (1.8以上)

```sh
#解压
tar -zxf StarRocks-2.3.0.tar.gz
tar -zxf jdk-8u341-linux-x64.tar.gz
#切换fe目录
cd StarRocks-2.3.0/fe
#添加元数据目录
mkdir -p meta
```

修改配置文件 conf/fe.conf 添加 JAVA_HOME=jdk解压路径


启动fe
```sh
bin/start_fe.sh --daemon
```

1. 通过浏览器查看 (配置文件默认 http_port 为 8030)，用户名root，没有密码
2. 通过mysql客户端登陆，root，没有密码
```sql
mysql -h ip -P9030 -uroot
mysql> show frontends \G
```

添加FE节点(两种角色)
```sql
ALTER SYSTEM ADD FOLLOWER "host:port";
ALTER SYSTEM ADD OBSERVER "host:port";
```

添加BE节点
```sql
ALTER SYSTEM ADD BACKEND  "host:port";
```


### FE集群

前提
1. 一台机器上只可以部署单个 FE 节点。
2. 所有 FE 节点的 http_port 需保持相同。
3. FE 节点之间的时钟相差不能超过5s。可使用 NTP 协议校准时间。

新FE新节点添加到现有集群时，需要指定一个节点为helper
```sh
./bin/start_fe.sh --helper host:port --daemon
```

FE两种角色
   * Follower：复制协议的可投票成员，参与选主和提交日志
   * Observer：非投票成员，用于异步订阅复制日志

1. 所有更改状态操作都由 Leader 节点执行
2. 更改操作可以由非 Leader 节点发起，继而转发给 Leader 节点执行，
3. 读操作可以直接在非 Leader 节点上执行，但需要等待非 Leader 节点的状态已经同步到最近一次更改操作的 LSN，因此非 Leader 节点的读写操作满足顺序一致性。
4. Observer 节点能够增加 FE 集群的读负载能力，对时效性要求放宽的非紧要用户可以选择读 Observer 节点。
