## 基本操作-HTTP

因为es是RESTful风格的，所有操作都可以通过http来实现
index：要存储数据，必须要有索引，即一个索引下存很多数据，虽然和关系型数据库的库不同，但是也可以理解成一个库
type：6.x之后一个index下只能有一个type，7.x后type概念已经被删除

### 索引

```sh
#创建索引,索引名为test，默认1分片一副本
curl -X PUT http://127.0.0.1:9200/test
#创建索引，3分片1副本，也就是一共6个分片，3个主分片，每个主分片1个副本，3个副本分片
curl -X PUT -H "Content-Type: application/json" -d '{"settings" : {"number_of_shards" : 3,"number_of_replicas" : 1}}' http://127.0.0.1:9200/test



#删除索引
curl -X DELETE http://127.0.0.1:9200/test

#查看单个索引
curl -X GET http://127.0.0.1:9200/test
```
```sh
#查看所有索引，详细信息
curl -X GET http://127.0.0.1:9200/_cat/indices?v

health status index                           uuid                   pri rep docs.count docs.deleted store.size pri.store.size
yellow open   test                            bymlkkslRWy-nbE3hPnqcw   1   1          5            1     13.3kb         13.3kb

health
    green:      所有主分片和副本分片全都正常
    yellow:     所有主分片正常，副本分片没有全部正常
    red:        所有主分片没有全部正常

pri             主分片数量
rep             副本数量
docs.count      可用文档数
docs.deleted    逻辑删除文档数
store.size      所有分片占用大小
pri.store.size  主分片占用大小
```

### 文档

es的文档即存储的数据，也就是一个json
type为 _doc 表示数据类型为文档，在新版本中type概念已弱化，未来可能删除，目前一个index下只能存在一种type，即创建的第一个文档type为aaa，则之后创建的文档类型也必须为aaa

```sh
#创建文档，不指定id，es会自动分配一个id
curl -X POST -H "Content-Type: application/json" -d '{"name":"张三","age":14}' http://127.0.0.1:9200/test/_doc/

#创建文档，指定id为111，指定id的情况下，请求为幂等性，所以也可以用PUT方法，
#更新整个文档，，此id的文档如果不存在则创建，存在则修改，看返回的结构是 "result": "updated" 则表示修改
curl -X POST -H "Content-Type: application/json" -d '{}' http://127.0.0.1:9200/test/_doc/111
curl -X PUT -H "Content-Type: application/json" -d '{}' http://127.0.0.1:9200/test/_doc/111

#修改文档部分内容,修改name字段为"李四"
curl -X POST -H "Content-Type: application/json" -d '{"doc":{"name":"李四"}}' http://127.0.0.1:9200/test/_update/111

#删除文档
curl -X DELETE http://127.0.0.1:9200/test/_doc/111
```


```sh
#查询index为test下的id为111的文档
curl -X GET http://127.0.0.1:9200/test/_doc/111

#查询index为test下的所有文档
curl -X GET http://127.0.0.1:9200/test/_search
```
