## sqlserver备份
先安装sqlcmd

```sh
#!/bin/bash

# 设置变量
DB_NAME="MyDatabase"
BACKUP_PATH="/path/${DB_NAME}_$(date +%Y%m%d).bak"
SQL_SERVER_IP="x.x.x.x"
SA_PASSWORD="YourStrong@Passw0rd"


# 备份命令
sqlcmd -S $SQL_SERVER_IP \
    -U SA \
    -P $SA_PASSWORD \
    -Q "BACKUP DATABASE [$DB_NAME] TO DISK = N'$BACKUP_PATH' WITH FORMAT, MEDIANAME = 'MyDatabaseBackup', NAME = 'Full Backup of $DB_NAME';"

# 打印结果
echo "Database $DB_NAME backed up to $BACKUP_PATH"
```

**注意：** 不管sqlcmd在哪里执行，备份的 BACKUP_PATH 路径都是 sqlserver 所在的机子上，需要手动拷贝到其他地方

## sqlserver恢复

先安装sqlcmd

```sh
#!/bin/bash

# 设置变量
DB_NAME="MyDatabase"
BACKUP_PATH="/path/$BACKUP_FILE"                #备份文件路径
SQL_SERVER_IP="x.x.x.x"                         # SQL Server 实例的 IP 地址
SA_PASSWORD="YourStrong!Passw0rd"

# 恢复命令
sqlcmd -S $SQL_SERVER_IP \
    -U SA \
    -P $SA_PASSWORD \
    -Q "RESTORE DATABASE [$DB_NAME] FROM DISK = N'$BACKUP_PATH' WITH FILE = 1, NOUNLOAD, REPLACE, STATS = 10;"

# 打印结果
echo "Database $DB_NAME restored from $BACKUP_PATH"
```



## 日志格式




| 恢复模式    | 说明                                   | 特点                               | 场景                       |
| ----------- | -------------------------------------- | ---------------------------------- | -------------------------- |
| SIMPLE      | 自动截断事务日志，不能做日志链备份     | 日志容易收缩，但不能做点时间还原   | 开发、测试环境             |
| FULL        | 记录所有事务，必须定期备份日志         | 支持还原到任意时间点，适合生产环境 | 生产系统（有日志备份）     |
| BULK_LOGGED | 在 FULL 的基础上，批量操作写入最少日志 | 提高性能，适合大导入大批量写入     | 批量导入数据时（临时设置） |




如果遇到开发、测试环境之类的，要收缩日志文件，又因为恢复模式设置为FULL的情况

则
```sql
-- 先选择数据库
USE 库名;
GO

-- 查询数据库的日志逻辑名，
SELECT name AS LogicalName, physical_name, type_desc
FROM sys.database_files
WHERE type_desc = 'LOG';

-- 直接设置恢复模式为 SIMPLE
ALTER DATABASE SHDB_SH11 SET RECOVERY SIMPLE;
GO

-- 收缩日志，填写 日志逻辑名，前面查询出来的 LogicalName
DBCC SHRINKFILE (SHDB_SH11_log, 10);  -- 单位是 MB
GO
```



如果是生产环境，则先备份日志文件
```sql
-- 备份到E盘SQLBackup目录下
BACKUP LOG [YourDBName] 
TO DISK = N'E:\SQLBackup\YourDBName_Log.trn' 
WITH INIT, COMPRESSION;

-- 收缩到10G，建议10G就可以，不能太小，YourDBName_log 可以查找一下
USE [YourDBName];
GO

-- 可选，查找日志文件名，后缀为 _log 的那个，默认是 blank_Log
SELECT name from sys.database_files

-- 收缩
DBCC SHRINKFILE (YourDBName_log, 10240);
```
**如果日志文件没有变小，则多备份几次日志文件，然后名字要区分，比如第一次是xxx-1.trn，再备份一次xxx-2.trn**
