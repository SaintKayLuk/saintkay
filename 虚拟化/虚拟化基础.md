# 虚拟化分类

* 技术角度分类
  * 全虚拟化技术
  * 半虚拟化技术
* 架构类型分类
  * 寄居架构
  * 裸金属架构



全虚拟技术
```
Guest OS    <-->    Hypervisor(VMM)     <-->    Hardware

虚拟机所有指令经过 Hypervisor 和硬件交互
```

半虚拟化技术(不常用)
```
Guest OS    <-->    Hypervisor(VMM)     <-->    Hardware
            <-------------------------->

对操作系统做了优化，增加了新的API，某些指令可以直接作用于硬件资源，Hypervisor 的负担减轻
```

寄居架构
```
Guest OS    <-->    Hypervisor(VMM)     <-->    Host System     <-->    Hardware

在操作系统上安装和运行虚拟化软件，依赖于主机操作系统
例如：VMware Workstation
```

裸金属架构
```
Guest OS    <-->    Hypervisor(VMM)     <-->    Hardware

直接在硬件上安装虚拟化软件，相当于主机操作系统就是虚拟化程序，再在此虚拟化程序上安装操作系统，
例如：VMware ESXi Server
```
