几种网络模式

* bridge(默认)
* host
* none
* overlay
* ipvlan
* macvlan

docker进程启动后，会在宿主机创建一个 docker0 虚拟网卡，容器之间网络通信，容器与外部网络通信都通过 docker0

### bridge：通过 veth pair 来实现

1. 容器内创建出一个网络，eth0
2. 宿主机创建一个 veth* 网络，相当于容器内的 eth0
3. 相当于虚拟机的 NAT 模式


创建一个虚拟网络设备对（veth pair），一端在容器内部，一端在外部，连接docker0

```       
eth0 --> veth* --> docker0
```

### host模式

1. 容器和宿主机使用同一网络，即容器内看到的网络和主机一样
2. 主机不会创建虚拟网卡
3. 相当于虚拟机的桥接模式


### overlay模式：通过 VXLAN  来实现

* 集群网络模式
* 不同宿主机的容器之间的网络通信

**数据流程**
1. 创建一个 VXLAN 接口（如 vxlan0），并将主机的 bridge 接口连接到 VXLAN 接口。
2. 发送数据时，数据首先通过 veth pair 进入主机的 bridge 接口
3. 然后通过 VXLAN 接口封装为 UDP 包，穿过物理网络到达 Host2 的 VXLAN 接口
4. Host2 的 VXLAN 接口接收到封装的数据包后解封装
5. 并通过 bridge 接口和 veth pair 将数据传递给容器2


VXLAN 接口负责在不同主机之间的路由和封装/解封装工作。由于 VXLAN 封装在 Layer 3 层（IP 层）进行，所以它可以跨越不同的物理网络和子网。

```
+----------------+                       +----------------+
|    Host 1      |                       |    Host 2      |
| +------------+ |                       | +------------+ |
| | Container1 | |                       | | Container2 | |
| +------------+ |                       | +------------+ |
|      |         |                       |      |         |
| +------------+ |                       | +------------+ |
| |  veth0     | |                       | |  veth0     | |
| +------------+ |                       | +------------+ |
|      |         |                       |      |         |
| +------------+ |                       | +------------+ |
| |  bridge0   | |                       | |  bridge0   | |
| +------------+ |                       | +------------+ |
|      |         |                       |      |         |
| +------------+ |                       | +------------+ |
| |  vxlan0    | | <--- VXLAN Tunnel --> | |  vxlan0    | |
| +------------+ |                       | +------------+ |
|      |         |                       |      |         |
| +------------+ |                       | +------------+ |
| |  eth0      | |                       | |  eth0      | |
| +------------+ |                       | +------------+ |
+----------------+                       +----------------+
```

### IPvlan

* L2 模式（Layer 2 mode）：
  * 容器共享同一个二层网络，所有的容器都连接到一个虚拟交换机，类似于传统的以太网交换机。
  * 容器可以直接通信，不需要路由。
  * 适用于需要与外部网络通信或直接连接的场景。
* L3 模式（Layer 3 mode）：
  * 每个容器都有一个独立的 IP 子网，通过路由器进行通信。
  * 适用于需要更高隔离性和独立性的场景。
  * 容器之间的通信需要路由，适合多租户环境。



L2模式：
```
+----------------+                       +----------------+
|    Host 1      |                       |    Host 2      |
| +------------+ |                       | +------------+ |
| | Container1 | |                       | | Container2 | |
| +------------+ |                       | +------------+ |
|      |         |                       |      |         |
| +------------+ |                       | +------------+ |
| |  ipvlan0   | |                       | |  ipvlan0   | |
| +------------+ |                       | +------------+ |
|      |         |                       |      |         |
| +------------+ |                       | +------------+ |
| |   eth0     | | <---- L2 Network ---> | |   eth0     | |
| +------------+ |                       | +------------+ |
+----------------+                       +----------------+
```

L3模式：
```
+----------------+                       +----------------+
|    Host 1      |                       |    Host 2      |
| +------------+ |                       | +------------+ |
| | Container1 | |                       | | Container2 | |
| +------------+ |                       | +------------+ |
|      |         |                       |      |         |
| +------------+ |                       | +------------+ |
| |  ipvlan0   | |                       | |  ipvlan0   | |
| +------------+ |                       | +------------+ |
|      |         |                       |      |         |
| +------------+ |                       | +------------+ |
| |   eth0     | | <---- L3 Network ---> | |   eth0     | |
| +------------+ |                       | +------------+ |
+----------------+                       +----------------+
```

### macvlan

* 每个容器可以有一个独立的 MAC 地址，允许容器在物理网络上独立存在。
* 不使用 NAT：容器的网络流量不经过 NAT，直接与物理网络上的其他设备进行通信。
