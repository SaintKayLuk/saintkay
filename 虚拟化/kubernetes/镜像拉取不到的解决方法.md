# 镜像拉取不到的解决方法

## 可以修改 image 的参数

如果能找到直接下载的，直接修改
如果网上没有其他镜像源，则通过阿里云镜像仓库拉取海外镜像，来手动构建一个镜像


1. github创建仓库
2. 根据路径创建对应的Dockerfile
3. 阿里云容器镜像服务，添加仓库
4. 对应github的地址
   1. 类型分支-main
   2. 上下文选择对应的Dockerfile的路径
   3. Dockerfile文件夹就默认
   4. 版本选对应的般般
5. 海外构建



## 不可以修改 image 参数，但是没有带 sha256的值，只有版本号


例如 calico 通过 tigera-operator 来安装 

如果能找到地址，则直接下载下来，再修改 tag
如果找不到地址，则还是通过阿里云构建，再改tag

例如：从 quay.io 下载镜像，然后改为 docker.io 地址的
```sh
ctr -n k8s.io image pull quay.io/calico/node:v3.25.2
ctr -n k8s.io image tag  quay.io/calico/node:v3.25.2 docker.io/calico/node:v3.25.2
```
