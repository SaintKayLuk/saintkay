<!-- 
/var/lib/kubelet/kubelet.yaml
这是 kubelet 的主要配置文件，包含了 kubelet 的运行时配置，如 cgroup 驱动、证书位置、网络设置等。
这个文件通常在 kubelet 启动时使用，以定义其行为和管理的参数。
/etc/kubernetes/kubelet.conf:

这是 kubelet 用于与 Kubernetes API 服务器通信的配置文件，包含了 API 服务器的地址、认证信息（如 token 或证书）和其他访问控制相关的设置。
这个文件主要用于确保 kubelet 能够安全地与 API 服务器交互。
简单来说，config.yaml 定义了 kubelet 的运行方式，而 kubelet.conf 则定义了 kubelet 如何与 Kubernetes 集群进行交互。 -->
