## 检查设置

### 检查每个节点唯一主机名，MAC地址，product_uuid

```sh
#查看主机名
hostname
#设置主机名
hostnamectl set-hostname xxx

#查看MAC地址
ip link 或 ifconfig

#查看product_uuid
cat /sys/class/dmi/id/product_uuid
```

### 关闭firewalld,关闭selinux,关闭swap，添加hosts映射，时间同步

```sh
#关闭防火墙，开机禁启
systemctl disable firewalld --now
#关闭selinux，重启生效
sed -i "/^SELINUX=/c SELINUX=disabled" /etc/selinux/config
#禁用swap，重启生效
sed -i "/swap/d" /etc/fstab

#所有节点 /etc/hosts 文件添加ip和主机名映射，根据自己ip和hostname
cat >> /etc/hosts << EOF
192.168.44.146 k8smaster
192.168.44.145 k8snode1
192.168.44.144 k8snode2
EOF

#时间同步。。。
。。。。。
```

### 允许 iptables 检查桥接流量，开启ip4路由转发
```sh
cat <<EOF | sudo tee /etc/modules-load.d/k8s.conf
br_netfilter
EOF

#加载内核模块
sudo modprobe overlay
sudo modprobe br_netfilter


# 设置所需的 sysctl 参数，参数在重新启动后保持不变
cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-ip6tables = 1
net.bridge.bridge-nf-call-iptables = 1
net.ipv4.ip_forward = 1

fs.inotify.max_user_instances=1024
EOF

# 应用 sysctl 参数而不重新启动
sysctl --system
```

验证一下
```sh
lsmod | grep br_netfilter
lsmod | grep overlay
```

验证一下
```sh
sysctl net.bridge.bridge-nf-call-iptables net.bridge.bridge-nf-call-ip6tables net.ipv4.ip_forward
```


## 安装runtime kubelet 


### 安装 runtime
runtime这里用containerd
```sh
#调用链
kubelet -> dockerd -> containerd -> containerd-shim -> runC容器
kubelet -> containerd -> containerd-shim -> runC容器     
```


**如果用flannel则下载带cni的包，也可以手动安装cni**
**如果用calico则下载不带cni的包**



```sh
# 如果是 1.20.x 版本，则下载 1.4.x版本的版本
wget https://github.com/containerd/containerd/releases/download/v1.4.13/cri-containerd-1.4.13-linux-amd64.tar.gz


#如果是 1.25.x 版本，则下载 1.16.x 版本
wget https://github.com/containerd/containerd/releases/download/v1.6.20/cri-containerd-1.6.20-linux-amd64.tar.gz

tar Czxvf / cri-containerd-1.6.20-linux-amd64.tar.gz
# 或，tar的写法不同
tar -zxvf cri-containerd-1.6.20-linux-amd64.tar.gz -C /

# 如果下载的带cni的包，则需要手动删除containerd的cni配置
# rm -f /etc/cni/net.d/10-containerd-net.conflist

mkdir -p /etc/containerd
containerd config default > /etc/containerd/config.toml
```

<!-- /run/containerd/containerd.sock -->


**修改config.toml**

修改 pause 镜像地址
```sh
#sandbox_image = "registry.k8s.io/pause:3.6"
#        ↓改为↓
#sandbox_image = "registry.aliyuncs.com/google_containerspause:3.6"

sed -i 's/registry.k8s.io\/pause:3.6/registry.aliyuncs.com\/google_containers\/pause:3.8/g' /etc/containerd/config.toml
```

修改 SystemdCgroup
```sh
# SystemdCgroup = false
#         ↓改为↓
# SystemdCgroup = true

sed -i 's/SystemdCgroup = false/SystemdCgroup = true/g' /etc/containerd/config.toml
```

启动 containerd 并加入开机自启
```sh
systemctl enable containerd --now
```


如果需要手动安装cni插件，注意cni版本和k8s版本
```sh
wget https://github.com/containernetworking/plugins/releases/download/v1.2.0/cni-plugins-linux-amd64-v1.2.0.tgz
tar -xvf cni-plugins-linux-amd64-v1.2.0.tgz -C /opt/cni/bin/
```


## 添加镜像源

### 添加 yum 源

添加官方源(访问不了用阿里云源)
```sh
cat <<EOF | sudo tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://packages.cloud.google.com/yum/repos/kubernetes-el7-\$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://packages.cloud.google.com/yum/doc/yum-key.gpg https://packages.cloud.google.com/yum/doc/rpm-package-key.gpg
exclude=kubelet kubeadm kubectl
EOF
```

添加阿里云源
```sh
cat > /etc/yum.repos.d/kubernetes.repo << EOF
[kubernetes]
name=Kubernetes
baseurl=https://mirrors.aliyun.com/kubernetes/yum/repos/kubernetes-el7-x86_64
enabled=1
gpgcheck=0
repo_gpgcheck=0
gpgkey=https://mirrors.aliyun.com/kubernetes/yum/doc/yum-key.gpg https://mirrors.aliyun.com/kubernetes/yum/doc/rpm-package-key.gpg
EOF
```


### 添加 apt 源


添加阿里云源
```sh
apt update && apt install -y apt-transport-https

#curl https://mirrors.aliyun.com/kubernetes/apt/doc/apt-key.gpg | apt-key add - 
curl -fsSL https://mirrors.aliyun.com/kubernetes/apt/doc/apt-key.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-aliyun.gpg

cat <<EOF >/etc/apt/sources.list.d/kubernetes.list
deb [signed-by=/etc/apt/keyrings/kubernetes-aliyun.gpg] https://mirrors.aliyun.com/kubernetes/apt/ kubernetes-xenial main
EOF


apt update
```
