## 生成证书

使用 cfssl


先创建2个配置文件
```sh
cat > ca-config.json <<EOF
{
    "signing": {
        "default": {
            "expiry": "168h"
        },  
        "profiles": {
            "kubernetes": {
                "expiry": "8760h",
                "usages": ["signing","key encipherment","server auth","client auth"]   
            }
        }   
    }   
}
EOF
```

```sh
cat > ca-csr.json <<EOF
{
  "CN": "Kubernetes",
  "CA":{
    "expiry":"175200h"
  },
  "key": {
    "algo": "rsa",
    "size": 2048
  },
  "names": [
    {
        "C": "CN",
        "ST": "Zhejiang",
        "L": "Hangzhou",
        "O": "Kubernetes"
    }
  ]
}
EOF
```
