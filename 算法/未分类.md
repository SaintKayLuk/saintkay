

**时间复杂度**：算法运行所需要的 时间量级（执行了多少步）
**空间复杂度**：算法运行过程中 额外占用了多少内存



#### 时间复杂度
计算时间复杂度的时候，我们取最坏条件，即运行次数无限大

例1：
```java
for(int i = 0 ; i < n ; i++){       //<- 从 0 到 n，执行 n+1 次
    a++;                            //<- 从 0 到 n-1，执行 n 次
}
```
执行了 n+1+n = 2n+1 次，n无限大的时候
```
      忽略1      n乘2近似n 
2n+1 ------> 2n ---------> n   
```



例2：
```java
for(int i = 0 ; i < n ; i++){           // n+1
    for(int j = 0 ; j < m ; j++){       // n*(m+1)
        num++;                          // n*m
    }
}
```
执行 (n+1)+n*(m+1)+n*m = 2nm+2n+1，当n和m都无限大的时候，n等于m
```
          忽略1           n近似m           2n²加多少可以忽略        是否给n²乘2无关紧要
2nm+2n+1 -------> 2nm+2n -------> 2n²+2n ------------------> 2n² -------------------> n²
```


用大写的 O + 频率 来表示时间复杂度，例如 O(n)

**常见的时间复杂度从快到慢：**
| 复杂度       | 示例                       | 含义                         |
| ------------ | -------------------------- | ---------------------------- |
| O(1)         | 访问数组中的某个元素       | 不管多大，只做一步操作       |
| O(log n)     | 二分查找                   | 每次都减半，缩小问题规模     |
| O(n)         | 遍历一个长度为 n 的数组    | 与输入规模线性相关           |
| O(n log n)   | 快排、归并排序             | 线性增长 + 每次减半处理      |
| O(n²)        | 双层嵌套循环（如冒泡排序） | 每个元素都对每个元素操作     |
| O(2ⁿ), O(n!) | 递归暴力解、全排列         | 极度爆炸，不能用于大规模输入 |

#### 空间复杂度

指的是算法在运行过程中，额外占用的内存空间大小（不包括输入本身）



**常见的空间复杂度：**
| 复杂度 | 示例                    |
| ------ | ----------------------- |
| O(1)   | 使用几个固定变量        |
| O(n)   | 创建一个长度为 n 的数组 |
| O(n²)  | 创建二维数组如 n×n 矩阵 |


例1： 空间复杂度为O(n)
```java
int[] arr = new int[n]; // 创建了长度为 n 的数组
```

例2：空间复杂度为 O(n²)
```java
int[][] matrix = new int[n][n]
```
