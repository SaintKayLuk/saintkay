# 列表 list

1. 相当于java的list
2. 长度可变
3. 列表可以保存不同类型数据
4. 用[]表示


```py
#创建一个空列表 
my_list = []
#创建一个3个元素的列表
my_list = [10, 'hello', True, None]


# 添加元素，在列表末尾添加
my_list.append("good")
# 删除元素，删除列表mysql索引为2的值
del my_list[2]
# 删除列表中的 'hello'
my_list.remove('hello')

#获取列表索引第二个值
print(my_list[1])
#获取列表索引倒数第一个，负数则从末尾开始
print(my_list[-1])
```



# 字典 dict


1. 相当于java的集合Map
2. 用{}表示，key:value
3. 类似于json格式
4. key不建议重复，重复的key，后面的value会覆盖前面的value

例：创建一个字典
```py
my_dict = {'a': 1, 'b': 'hello'}
```
