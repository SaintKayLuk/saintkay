


## 捕获异常
```py
try:
    #异常代码
    pass
except:
    #出现异常执行的代码 
    pass


#指定异常类型为 NameError
#最后捕获所有异常
try:
    pass
except NameError:
    pass
except Exception:
    pass

#输出异常信息
try:
    pass
except Exception as e:
    print(e)


#没有出现异常执行else语句
try:
    pass
except Exception:
    pass
else:
    pass


#finally语句，无论有没有异常，都执行
try:
    pass
except Exception:
    pass
finally:
    pass
```

## 抛出异常

```py
#可添加自定义内容
raise Exception('我是异常')
```

## 自定义异常

```py
#继承一个异常类
class MyError(Exception):
    pass
```
