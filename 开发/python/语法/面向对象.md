#### 使用class 创建类
```py
# 创建类的时候 MyClass 和 MyClass() 效果一样，但是没有父类继承的时候，一般不写()
class MyClass:

    # 类属性
    # 可以通过类和实例来访问，但是只能通过类来修改
    class_name = None

    #构造方法
    #self是类本身，相当于java的this
    def __init__(self):
        # 实例属性只能通过实例对象来访问和修改
        self._instance_name = None


    #添加注解，相当于get方法
    @property
    def instance_name(self):
        return self._name

    # 通过 属性名.setter 注解，设置此方法为set方法
    # 有set方法必须要有get方法
    @instance_name.setter
    def instance_name(self, instance_name):
        self._instance_name = instance_name


    # 类方法，cls相当于类本身，和普通方法区别就是cls和self
    # 可以通过类调用，也可以通过实例调用
    @classmethod
    def class_method(cls):
        pass


    # 静态方法
    @staticmethod
    def static_method():
        pass


```

* **属性 _name 和 __name**
  * _name 一般作为类的内部属性，虽然也能直接调用，但推荐使用get set方法来调用
  * __name 一般作为类的私有属性，不建议外部调用，但是可以通过 **_类名__属性名**来调用
    * ```py
      class A:
        def __init__(self):
            self.__name = 'saintkay' 
      a = A()
      # 通过_A__name 则能在外部调用类的私有属性，但不建议
      a._A__name
      ```

* **方法 _method() 和 __method()**
  * _method
    * 一般作为内部方法，不建议外部调用，虽然也能调用
    * 能被子类继承和重写
  * __method
    * 一般作为私有方法，不能直接调用
    * 不能被子类直接继承和重写
    * 和属性一样 可以通过 _类名__method()来使用

**python中没有强制私有属性和方法，只有推荐，不像java一样，私有属性和方法，肯定调用不了**
**python通过 __ 来指定私有的，不管作用与属性还是方法，都相当于在前面加上 _类名**


#### 继承

python支持多重基础，一个类可以继承多个父类
```py
# 类名后面加()，里面写继承的父类
# 创建类 A 继承 B,C,D
class A(B, C, D):
    pass
```

B通过 super()来调用A的属性a
```py
class A:
    a = 1

class B(A):
    a = 2
    def get_a(self):
        return super().a
```
