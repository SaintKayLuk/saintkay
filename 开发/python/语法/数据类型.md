## 数据类型

* 整数：所有都是int类型，无上限大小
  ```py
  # 无论什么进制，输出的时候都以十进制显示
  # 二进制的10，相当于十进制2
  a = 0b10 
  #八进制10，相当于十进制8
  c = 0o10
  #十六进制，相当于十进制16
  c = 0x10
  ```
* 小数：所有小数都是float类型
  ```py
  a = 1.23
  b = 3.45
  ```
* 布尔值(bool)：首字母大写，也相当于整数类型，True=1，False=0
  * True
  * Flase
* 空值：相当于Null
  * None
* 字符串
  ```py
  # 可以使用单引号、双引号、三引号(3个单引号或者3个双引号)
  # 建议使用单引号
  s = 'hello，世界'
  s = "hello，世界"
  # 三引号会保留格式，例如换行等
  s = '''hello，世界'''
  s = """hello，世界"""
  ```
  * 转义符
  ```py
  # \' 表示'
  # \" 表示"
  # \t 表示制表符
  # \n 表示换行符
  # \\ 表示反斜杠
  # \uxxxx 表示Unicode编码
  ```
  * 字符串拼接
  ```py
  a = 'hello'
  b = 'world'
  s = a + b
  print(s)      # 结果为 helloworld
  print(a+b)    # 结果为 helloworld
  print(a,b)    # 结果为 hello world
  ```
  * 格式化字符串
  ```py
  # %s 字符串占位符
  # %f 浮点数占位符
  # %d 整数占位符
  
  a = 'world'
  print('hello %s'%a)   # 结果为 hello world
  a = 123.456
  print('hello %.2f'%a) # 结果为 hello 123.46 保留2位小数
  a = 123
  print('hello %d'%a)   # 结果为 hello 123
  ```
  * 复制字符串
  ```py
  s = 'abc'
  # 复制3次s的值
  s = s * 3     # 结果为 abcabcabc
  ```

### 类型检查

判断变量的类型

```py
print(type(1))          # 结果为 <class 'int'>
print(type(1.5))        # 结果为 <class 'float'>
print(type(True))       # 结果为 <class 'bool'>
print(type('hello'))    # 结果为 <class 'str'>
print(type(None))       # 结果为 <class 'NoneType'>
```

### 类型转换

* 四种类型转换函数
  * int() 
    * 布尔类型转换为 1 和 0
    * 小数类型去除小数，取整数部分
    * 字符串类型只有是整数的可以转，不是整数则不能转
  * float() 
    * 布尔类型转换为 1.0 和 0.0
    * 整数类型转换为 xxx.0
    * 字符串类型为小数和整数可以转，其他则不能转
  * bool() 
    * 所有类型都能转换为布尔值
    * 0 和 0.0 和 None 和 '' 等转换为Flase
    * 所有非0或者有值的转换为True
  * str()
    * 所有类型都能转换为字符串类型，相当于对原有值加了一个引号

## 变量

* 变量命名规范
  * 区分大小写
  * 不能使用未赋值的变量
  * 动态类型，变量可以随意赋值
  * 变量命名：大小写字母 + 数字 + 下划线

```py
# 给a赋值10
a = 10
# 打印a的值
print(a)
# 不能打印没有赋值的b
print(b)
# 可以继续给a赋值其他类型的值
a = '哈哈'
```


## 运算符

* 算术运算符
  ```py
  # + 加法运算符，字符串会拼接，数值会相加
  # - 减法运算符
  # * 乘法运算符，字符串会进行复制，数值相乘
  # / 除法运算符，运算时结果总会返回一个浮点类型
  # // 整除，只会保留计算后的整数位，总会返回一个整型
  # ** 幂运算，求一个值的几次幂
  # % 取模，求两个数相除的余数
  ```
* 赋值运算符
  ```py
  # =       右侧的值赋值给左侧的变量
  # +=      a += 5 相当于 a = a + 5 
  # -=      a -= 5 相当于 a = a - 5 
  # *=      a *= 5 相当于 a = a * 5 
  # **=     a **= 5 相当于 a = a ** 5 
  # /=      a /= 5 相当于 a = a / 5 
  # //=     a //= 5 相当于 a = a // 5 
  # %=      a %= 5 相当于 a = a % 5 
  ```
* 关系运算符
  ```py
  # 如果关系成立，返回True，否则返回False
  # >
  # >=
  # < 
  # <=
  # ==      比较两个对象的值是否相等，比较的是值
  # !=      比较两个对象的值是否不相等
  # is      比较两个对象是否是同一个对象，比较的是对象的id
  # is not  比较两个对象是否不是同一个对象
  ```
* 逻辑运算符
  ```py
  # not     非，相当于取反
  # and     与，两边都为True才为True
  # or      或，一边为True就为True
  ```
  当运算非布尔值的时候，会将需要运算的值转换为布尔值进行运算，返回原结果
  ```py
  # 与运算找False，如果第一个是False，则不会继续判断第二个值
  # 例：
  1 and 2 #返回2
  0 and 2 #返回0

  
  # 或运算找True，如果第一个值是True，则不会继续判断第二个值
  # 例：
  1 or 2 #返回1
  0 or 2 #返回2
  ```
  
* 条件运算符
  ```py
  # 语句1 if 条件表达式 else 语句2
  # 条件成立执行语句1，不成立执行语句2

  # 例：如果a大于b，大于hello，否则打印world
  a = 3
  b = 5
  print('hello') if a > b else print('world') 
  ```
