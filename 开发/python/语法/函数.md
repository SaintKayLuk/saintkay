# 函数

1. 用 def 表示
2. 全局变量和局部变量
3. return返回
4. 可以设置默认参数的值
5. 函数内第一行字符串是文档说明，可通过 help() 方法查看
6. 通过 locals() 查看不同命名空间的变量，命名空间相当于字典
7. 参数和返回值都可以用函数


```py
# 第一行是文档，相当于注释
# 参数后可以跟类型，只是提示作用
# 例如一个参数 arg1 ，默认100，提示为int类型
def function_name(arg1: int = 100):
    '''
    这是文档，说明此方法的作用
    可通过三引号来换行
    '''
    方法体
    return    
```


```py
#传递2个参数
def function_name(arg1, arg2):


#设置 arg2的默认值为100，当不传递第二个参数的时候，则arg2默认为100
def function_name(arg1, arg2=100):


# 传递不定长参数
# *arg2 相当于一个元组，使用此方法时，把传递的除第一个参数以外的参数都放一个元组里
def function_name(arg1, *arg2):


# 关键字参数
# arg2相当于字典
def function_name(arg1, **arg2):

# 如果调用 function_name(arg1=1, arg2=2, arg3=3)
# 则arg2 和arg3 都会被接收为字典
```


### 调用函数的时候，直接传递元组、列表、字典等
```py
# 直接传元组
def function_name(*arg):

t=(1,2,3)
function_name(*t)

# 直接传字典，需要参数都有对应的

def function_name(arg1, arg2):
    
d = {'arg1': 100, 'arg2': 200}
function_name(**d)

```



### 函数的参数可以传其他函数
```py
#fu1作为fu2的参数
def fu1():
    print('hello')

def fu2(fu1)
    fu1()

```


### 匿名函数


没有函数名，用 lambda 来创建
```py
# 求2个数之和
# 以下两个函数作用相同，求参数 a和b 的和
def get_sum(a, b):
    return a + b

# :左边为参数，右边为执行代码
lambda a, b: a + b
```


### 装饰器

调用其他函数，通过@来调用，对函数进行封装

```py
def fu():


@fu
def fu1():


```
