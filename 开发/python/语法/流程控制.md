

## if 语句
```py
#后面跟一条语句，直接写后面，不常用
if 条件表达式 : 执行语句

#后面跟代码块，换行缩进
if 条件表达式 : 
    执行语句1
    执行语句2
    执行语句3

# if -else判断
if 条件表达式 :
    执行语句1
else :
    执行语句2

# if - elfi -else 判断
if 条件表达式1 :
    执行语句1
elif 条件表达式2 :
    执行语句2
elif 条件表达式3 :
    执行语句3
else :
    执行语句4    
```

**if-elif 中只会执行一个一个代码块，自上到下满足多个条件也也只执行第一个符合的**

例：判断 a 和 b 的大小，输出
```py
a=20
b=10

if a > b :
    print('a比b大')
else
    print('a比b小')
```







## while 语句

```py
while 条件表达式 :
    执行语句1
else :
    执行语句2
```

## for 语句

和 java 的 foreach 语法类似，和shell的for循环也类似

例：遍历列表的的值
```py
my_list = [1, 2, 3, 'hello', 'world']
for x in my_list:
    print(x)
```

循环指定次数，类似于int i=0，i<5 之类的语法
```py
# 循环5次，range(5)表示生成1-5的列表
for i in range(5):
    pass

```


## 其他

**continue**

跳过当次循环

**break** 

跳出当前循环

**pass**

占位符，例如还没想好需要做什么，先占用一下

```py
a = 0
if a < 5 :
    pass
else
    print('a不小于5')

```
