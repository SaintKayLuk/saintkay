

## open()方法
```py
open('file_name', mode='rt', encoding='utf-8')
```

* 第一个参数file_name 是需要打开的文件，默认是当前路径下的文件名，可以加路径，打开其他目录下的文件
* mode参数 打开文件
  * r 只读，**(默认)**
  * w 写，文件不存在创建文件，覆盖写入
  * a 写，文件不存在创建文件，追加写入
  * x 写，文件不存在创建文件，文件存在报错
  * r+ 读写，文件不存在报错，追加写入
  * w+ 读写，文件不存在创建文件，覆盖写入
  * a+ 读写，文件不存在创建文件，覆盖写入
  * t 以文本格式打开，**(默认)**
  * b 以二进制格式打开
* encoding参数：文件的编码格式


1. 读取文本文件时，以字符为单位
2. 读取二进制文件时，以字节为单位

## 打开关闭文件
```py
# 打开当前路径下的目录abc下的demo.txt文件
# 使用 with 语句来控制关闭，这样操作完自动关闭文件
file_name = 'abc/demo.txt'
with open(file_name) as file_obj:
    pass


# 添加异常处理
try:
    with open(file_name) as file_obj:
        pass
except FileNotFoundError:
    pass
```


## 读取文件
```py

with open('demo.txt') as file_demo:
    #读取文件所有内容
    file_demo.read()
    #读取5个字符
    file_demo.read(5)
    #判断是否可读，返回True和False
    file_demo.readable()
    #读取一行
    file_demo.readline()
    #返回一个列表，按每行为一个值
    file_demo.readlines()

    #打印每次读取的5个字符，并且不换行
    # print()每次默认换行，添加 end=''则不换行
    print(file_demo.read(5), end='')
```

read()方法返回读取的内容，当读完的时候则返回空字符串
则可以通过read()方法的返回值来判断文件是否读完
例：
```py
with open('demo.txt') as file_demo:
    while True:
        # 每次读取5个字符
        content = file_demo.read(5)
        # 当没有内容的时候，空字符串默认转换为False，则break退出
        if not content:
            break
```

## 写入文件

打开文件的时候，设置open()方法的参数mode
```py
#打开demo.txt文件，不存在则创建，并追加写入
with open('demo.txt', mode='a') as file_demo:
    file_demo.write('hello')
```

## 序列化和反序列化

* 序列化：把对象写入到文件中
  * dumps()
  * dump()
* 反序列化：把文件读取到对象中
  * loads()
  * load()

python中有2个模块可供序列化和反序列化
* json
* pickle

#### 序列化
```py
# 创建一个列表
l = ['a', 'b', 1233]
# 打开一个test.txt文件
with open('test.txt', mode='w') as f:
    # dumps()方法，将对象转换为str，再写入文件
    s = json.dumps(l)
    f.write(s)

    # dump()方法，直接传python对象和文件对象
    json.dump(l, f)
```

#### 反序列化
```py
# 使用 loads()方法将读取出的str转换为 列表，字典等
with open('test.txt', mode='r') as f:
    s = f.read()
    json.loads(s)

# 使用load()方法，直接传文件对象，转换为 列表，字典等
with open('test.txt', mode='r') as f:
    json.load(f)

```


## 其他

#### tell()获取当前读写坐标
```py
with open('demo.txt', mode='a') as file_demo:
    file_demo.tell()
```

#### seek()移动读写坐标
```py
with open('demo.txt', mode='a') as file_demo:
    file_demo.seek(5)

    # seek(offset: int, whence: int = 0)
    # seek()方法两个参数，第一个是要移动的位置
    # 第二个参数，可选0，1，2，默认0
    #   0从头开始
    #   1从当前位置开始
    #   2从末尾开始

    # 从当前位置往后移动5个坐标继续读写
    file_demo.seek(5, 1)
```


#### 其他

os模板

```py
import os

# 查看当前目录下文件，相当于ls
# 返回list
os.listdir()

# 查看上级目录
os.listdir('../')

# 获取绝对路径，相当于pwd
os.getcwd()

# 切换路径，切换到上级目录下的aaa目录下，即和当前目录同级的aaa目录
# 路径不存在则报错
os.chdir('../aaa')

# 新建目录，目录存在则报错
os.mkdir('abc')

# 删除目录，目录不存在报错
os.rmdir('abc')

# 新建一个a.txt文件，文件存在则报错
# 此方法在windows下会报错
os.mknod('a.txt')

# 删除文件 a.txt，文件不存在则报错
os.remove('a.txt')

# 重命名，也可以作为移动文件路径
# 把当前目录下的 a.txt 文件移动到 abc 目录下并重命名为 b.txt
os.rename('a.txt','abc/b.txt')
```
