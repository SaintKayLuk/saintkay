# RBAC




用户，角色，权限之间多对多关系
一个用户可以赋予多个角色，一个角色可以赋予多个用户，一个角色可以赋予多项权限

```
用户 <---> 角色 <---> 权限
```

## RBAC-1 模型

角色分层，高级角色拥有低级角色的权限，类似于角色继承，

父级角色的权限是自身及它的所有子角色的权限的综合


## RBAC-2 模型

* **互斥角色**：同一用户在两个互斥角色中只能选择一个
* **先决条件角色** ：指要想获得较高的权限要首先拥有低一级的权限。角色A为角色B的上级，要想为用户分配角色A，则必须先分配角色B
* **基数约束**：一个角色被分配的用户数量受限；一个用户可拥有的角色数目受限
* **运行时互斥**：允许一个用户具有两个角色，但在运行中不可同时激活这两个角色。
