#### @Override

用来指定方法重写的

#### @Deprecated

可以用来注解类、接口、成员方法和成员变量等，用于表示某个元素（类、方法等）已过时

#### @SuppressWarnings

取消编译器的警告

#### @SafeVarargs

用于需要检查参数的地方，加此注解则不提示警告

@SafeVarargs注解不适用于非 static 或非 final 声明的方法，
对于未声明为 static 或 final 的方法，如果要抑制 unchecked 警告，可以使用 @SuppressWarnings 注解。

#### @FunctionalInterface

1. 来指定某个接口必须是函数式接口
2. 只能修饰接口
3.  @FunctionalInterface 注解的作用只是告诉编译器检查这个接口，保证该接口只能包含一个抽象方法，否则就会编译出错
