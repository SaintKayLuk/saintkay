元注解就是给注解使用的注解

用 @interface 来定义一个注解


注解示例
```java
@Documented
@Target({ElementType.TYPE,ElementType.METHOD})
@Retention(RetentionPolicy.SOURCE)
@Inherited
public @interface TestAnnotation {}
```

#### 元注解

* **@Documented**
    用 @Documented 注解修饰的注解类会被 JavaDoc 工具提取成文档
* **@Target**
    用来指定一个注解的使用范围，即这个注解能用在什么地方，是一个 ElementType 类型的数组
  * ElementType.TYPE：用于类，接口，注释，枚举等
  * ElementType.FIELD：用于成员变量，枚举常量等
  * ElementType.METHOD：用于方法
  * ElementType.PARAMETER：用于方法形参
  * ElementType.CONSTRUCTOR：用于构造方法
  * ElementType.LOCAL_VARIABLE：用于局部变量
  * ElementType.ANNOTATION_TYPE：用于注解类型
  * ElementType.PACKAGE：用于包
  * ElementType.TYPE_PARAMETER
  * ElementType.TYPE_USE
* **@Retention**
   用于描述注解的生命周期，即注解保留的时间长短
  * RetentionPolicy.SOURCE：只在源文件中保留，即存在于 xxx.java
  * RetentionPolicy.CLASS：在编译文件中保留，即存在于 xxx.java 和 xxx.calss
  * RetentionPolicy.RUNTIME：运行时保留
* **@Inherited**
    是一个标记注解，用来指定该注解可以被继承


生命周期大小排序为 RetentionPolicy.SOURCE < RetentionPolicy.CLASS < RetentionPolicy.RUNTIME



#### 注解类型

根据注解是否包含成员变量，可以分为如下两类。
* 标记注解：没有定义成员变量
* 元数据注解：包含成员变量

```java
//标记注解
public @interface TestAnnotation {}

//元数据注解
public @interface TestAnnotation {
    //注解的成员变量
    String name();
    int age();
}
```

```java
//元数据注解
public @interface TestAnnotation {
    //注解默认成员变量
    String name() default "saintkay";
    int age() default 18;
}
```
