### 包名

* 包名全都小写
* 命名规则
  * 公司：com.公司名.项目名.模块名
  * 个人发起，非独立完成： indi.发起者名.项目名.模块名
  * 个人发起，独立完成，可分享的：  pers.个人名.项目名.模块名
  * 个人私有，独立完成，独自完成非公开的私人使用：  priv.个人名.项目名.模块名

### 类名

所有首字母大写

### 方法名

首字母小写，之后的单词首字母大写，驼峰原则
例如 
```java
public void myMethod(){}
```

### 常量名

常量全大写，多个单词用下划线分隔
```java
public static final MY_NAME = "saintkay";
```

### 变量名

和方法名类似，首字母小写，之后大写，驼峰原则
```java
public Long myMoney = 100000000L;
```
