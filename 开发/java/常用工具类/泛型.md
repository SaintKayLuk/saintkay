## 泛型

泛型可以在编译的时候检查类型安全，并且所有的强制转换都是自动和隐式的

泛型可以用任何字母代替，但是一般会约定几个
* E：一般在集合中使用，因为集合中存放的是元素
* T：一般在类，接口，方法中使用
* ?：表示不确定的java类型


#### 泛型指定 集合内元素类型
```java
public static void main(String[] args) {

    //不指定类型，则list里的元素是 Object
    List list = new ArrayList();
    list.add(1);
    // 默认取list元素是 Object，需要向下转型
    Object o = list.get(0);



    //指定list的泛型为 Integer，即存进去的元素都是 int 类型
    List<Integer> list = new ArrayList<>();
    list.add(1);
    //取元素出来的时候，默认就是泛型类型
    Integer i = list.get(0);
}
```

#### 泛型类 和 泛型接口


泛型类
```java
//定义泛型类，并且指定了2个泛型对象
public class C<T1, T2> {

    //泛型A为属性
    private T1 t1;

    //泛型B为方法入参
    public void method(T2 t2) {
        System.out.println(t2);
    }

    public static void main(String[] args) {

        //创建C的实例的时候指定C的泛型参数为 Integer 和 String
        C<Integer, String> c = new C<>();
        c.t1 = 1;
        c.method("参数B是字符串类型");
    }
}
```

泛型接口，和泛型类类似
```java
public interface I<T> {
    void method(T t);
}
```


#### 泛型方法

方法的入参和返回值都可以用泛型来指定

只有在方法签名中声明了泛型的方法才是泛型方法
仅使用了泛型类定义的类型参数的方法并不是泛型方法。


泛型方法，类并不需要是泛型类，和抽象方法和抽象类不同
```java
public class C {
    <T> T method(T t) {
        return t;
    }
    
    //多个泛型参数
    <T,S> T method(T t,S s) {
        return t;
    }
}
```

也可以使用类上定义的泛型
```java
public class C<T> {
    public T method(T t) {
        return t;
    }
}
```

类上定义的泛型和泛型方法中的泛型并无关系
```java
public class C<T> {

    //泛型方法中的泛型 T 和 类中的泛型 T 不同
    <T> T method(T t) {
        return t;
    }
}
```


类上定义的泛型类型不能在静态方法中使用
```java
public class C<T> {
    public static <E> E method(E e) {
        return e;
    }
}
```


#### 泛型通配符


```
<?>             被称作无限定的通配符，可以是任意类型
<? extends T>   被称作有上界的通配符，必须是T或者是T的子类
<? super T>     被称作有下界的通配符，必须是T或者是T的父类，接口
```


使用 extends 通配符表示可以读，不能写。
上界通配符示例
```java
public class C {

    public static void main(String[] args) {
        // 创建一个 List<Integer> 集合
        List<Integer> integerList = new ArrayList<>();
        integerList.add(1);
        integerList.add(2);
        // 将 List<Integer> 传入 printIntVal() 方法
        printIntVal(integerList);

        // 创建一个 List<Float> 集合
        List<Float> floatList = new ArrayList<>();
        floatList.add((float) 1.0);
        floatList.add((float) 2.0);
        // 将 List<Float> 传入 printIntVal() 方法
        printIntVal(floatList);
    }

    public static void printIntVal(List<? extends Number> list) {
        for (Number number : list) {
            System.out.println(number.intValue());
        }
    }
}
```


下界通配符示例
```java
public class C {

    public static void main(String[] args) {


        // 创建一个 List<? super Number> 集合
        List<Number> list = new ArrayList<>();
        // 添加 Float 类型的值
        list.add(new Float(1.1));
        fillNumList(list);

        List<Integer> list1 = new ArrayList<>();
        list1.add(1);
        fillNumList(list);
    }

    // 方法入参传 Integer泛型的List 或者 Integer 父类，接口的 List
    public static void fillNumList(List<? super Integer> list) {
        list.add(new Integer(2));
    }
}
```


无限定通配符
```
<?> 代表任意类型，包括null
```
