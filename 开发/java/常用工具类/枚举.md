
枚举是一堆常数的集合


## 枚举类

#### 简单的枚举类型
```java
public enum Day {
    MONDAY, 
    TUESDAY, 
    WEDNESDAY, 
    THURSDAY, 
    FRIDAY, 
    SATURDAY, 
    SUNDAY
}
```


#### 带方法的枚举类型
```java
public enum Day {
    MONDAY, 
    TUESDAY, 
    WEDNESDAY, 
    THURSDAY, 
    FRIDAY, 
    SATURDAY, 
    SUNDAY;

    public boolean isWeekend() {
        return this == SATURDAY || this == SUNDAY;
    }
}
```


#### 带构造函数和字段的枚举类型
```java
public enum E {
    A("a", 1),
    B("b", 2),
    C("c", 3);

    // 定义枚举属性
    private String s;
    private int i;

    // 参数顺序 决定了枚举值的参数顺序
    private E(String s, int i) {
        this.s = s;
        this.i = i;
    }

    // 添加 public 的get方法，用于获取枚举中的变量
    public String getS() {
        return s;
    }
    public int getI(){
        return i;
    }

}
```

#### 有自己实现方法的枚举类型
```java
public enum Operation {
    PLUS {
        @Override
        public Double apply(Double x, Double y) {return x + y;}
    },
    MINUS {
        @Override
        public Double apply(Double x, Double y) {return x - y;}
    },
    TIMES {
        @Override
        public Double apply(Double x, Double y) {return x * y;}
    },
    DIVIDE {
        @Override
        public Double apply(Double x, Double y) {return x / y;}
    };
    //抽象方法用于枚举常量来实现
    public abstract double apply(double x, double y);
}

//使用方式
public class Demo {
    public static void main(String[] args) {
        //调用枚举常量的方法
        Operation.PLUS.apply(1,2);
    }
}
```

## 枚举的方法

枚举其实就是个class，隐式继承了 抽象类Enum

```java
//枚举常量的名称，建议使用toString()方法
public final String name() {
    return name;
}

//返回此枚举常量的序号（其在其枚举声明中的位置，其中初始常量的序数为零）
public final int ordinal() {
    return ordinal;
}

//虽然和name()方法一样都是返回name属性，但是此方法可被覆盖，当存在更好的字符串形式时，枚举类型应重写此方法
public String toString() {
    return name;
}

//用于判断枚举等常量是否一致，注意需要传枚举类型进来，
//例如  Day.MONDAY.equals(Day.valueOf("TUESDAY"));
public final boolean equals(Object other) {
    return this==other;
}

//用于比较枚举的顺序，返回负整数、零或正整数
//WeekDay.MONDAY.compareTo(WeekDay.MONDAY);  返回 0
//WeekDay.MONDAY.compareTo(WeekDay.TUESDAY); 返回 -1
//WeekDay.SUNDAY.compareTo(WeekDay.FRIDAY);  返回 2
public final int compareTo(E o) {
    Enum<?> other = (Enum<?>)o;
    Enum<E> self = this;
    if (self.getClass() != other.getClass() && // optimization
        self.getDeclaringClass() != other.getDeclaringClass())
        throw new ClassCastException();
    return self.ordinal - other.ordinal;
}


//返回枚举常量的枚举类型，不同于getClass()方法，此方法只能用于枚举常量来调用
public final Class<E> getDeclaringClass() {
    Class<?> clazz = getClass();
    Class<?> zuper = clazz.getSuperclass();
    return (zuper == Enum.class) ? (Class<E>)clazz : (Class<E>)zuper;
}
```





```java
public static <T extends Enum<T>> T valueOf(Class<T> enumType,String name) {
    T result = enumType.enumConstantDirectory().get(name);
    if (result != null)
        return result;
    if (name == null)
        throw new NullPointerException("Name is null");
    throw new IllegalArgumentException(
        "No enum constant " + enumType.getCanonicalName() + "." + name);
}

//使用方式，明确枚举类型，使用对应的枚举类直接调用
WeekDay.valueOf("MONDAY");
//适用于动态确定枚举类型的场景，需要传入对应的枚举类calss
Enum.valueOf(WeekDay.class, "MONDAY");
```


##  EnumMap

1. EnumMap 是一个Map,但是它的key值是enum类型的
2. 这个map的size有最大值，就是enum的个数
3. EnumMap创建的时候需要传入enum类型，内部存的是一个数组

```java
public enum E {
    A,
    B,
    C;

    public static void main(String[] args) {

        // 创建 EnumMap 需要传入枚举类class，并且 key 为枚举类型，value自定义
        EnumMap<E, String> map = new EnumMap<>(E.class);

        map.put(A,"1");

    }
}
```
