## 继承

1. 子类实例化过程中调用父类的构造方法
2. 子类构造方法中没有指定调用父类的构造方法，则默认调用无参构造
3. 使用super调用父类构造方法，必须在构造方法内第一行
4. A继承B，B继承C，则实例化A的时候，先执行C的构造方法，再执行B的构造方法，最后执行A的构造方法

```java
public class C {
    public C() {
        System.out.println("C的无参构造");
    }
    public C(String s) {
        System.out.println("C的有参构造");
    }
}


public class B extends C {
    public B() {
        //显示调用父类的有参构造
        super("");
        System.out.println("B的无参构造");
    }
}



public class A extends B {
    public A() {
        System.out.println("A的无参构造");
    }

    public static void main(String[] args) {
        new A();
    }
}

```

输出结果
```
C的有参构造
B的无参构造
A的无参构造
```
