#### 可变参数

不指定参数数量，可变参数放最后一个
例如以下方法，可以传递多个int类型的参数


```java
public static void method(int... i){}

public static void method(String s,int... i){}
```


#### 构造方法

1. 实例化对象的时候会调用构造方法，不写默认无参构造方法
2. 构造方法没有返回值
3. 可以存在多个构造方法
4. 如果写了无参构造方法，则会调用自己写的无参构造方法

```java
public class A {
    //无参构造    
    public A(){}
    //有参构造
    public A(String s){}
}
```

 #### 方法重载

方法名相同，方法参数不同

```java
public void method(){}

public void method(int i){}
```


#### 方法重写

子类继承父类的时候，重写父类的方法
方法名，返回值，入参都相同

```java
public class A {
    //父类的方法
    public void method() {
        System.out.println("A的方法");
    }
}


public class B extends A {
    //子类的方法
    @Override
    public void method(){
        //使用super调用父类的方法
        super.method();
        System.out.println("B的方法");

    }
}

```
