## 接口

1. 接口用 interface 修饰
2. 接口可以 extend 多个接口
3. 实现接口的类，必须实现接口的所有抽象方法，除非是抽象类
4. 一个类可以同时实现多个接口

```java
public interface A extends B,C{
    //接口都为常量，且默认添加 static final，即 static final int i = 1;
    int i = 1;

    //接口内的方法除了 static 和 default方法外，其他的都为抽象方法，默认添加 abstract
    void method();


    //接口中的静态方法，可以直接使用 接口来调用    
    static void methodS() {
        System.out.println("接口的静态方法");
    }

    //接口中的默认方法，可以在实现类中直接调用
    default void methodD() {
        System.out.println("接口的默认方法");
    }

}
```

实现类示例
```java
public class D implements A {

    public static void main(String[] args) {
        //创建示例A，向上转型D
        A a = new D();

        //调用a的实现方法
        a.method();

        //调用默认方法
        a.methodD();
        
        //直接调用接口的静态方法
        A.methodS();

    }

    //实现接口的 method()方法
    @Override
    public void method() {
        System.out.println("A的方法");
    }


}

```
