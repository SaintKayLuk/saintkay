## 抽象类和抽象方法

1. 抽象方法和接口中方法类似，不能有方法体
2. 类中有抽象方法，那此类必须是抽象类
3. 子类继承抽象类，必须实现抽象方法，除非子类也是抽象类
4. 抽象类不能实例化
5. 用 abstract 关键字修饰抽象类和抽象方法
6. abstract 不能和 static、final、private 一起使用

```java
//用 abstract 修饰的抽象类
public abstract class A {

    //用 abstract 修饰的抽象方法
    abstract void method();

    //抽象类中的普通方法
    void method1(){}
    
}
```
