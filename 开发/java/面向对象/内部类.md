## 内部类

内部类提供了更好的封装，把内部类隐藏在外部类之中，不允许同一包中的其他类访问

* 内部类分类
  * 成员内部类
  * 静态内部类
  * 局部内部类
  * 匿名内部类


#### 成员内部类


```java
public class A {

    int i = 1;

    public static void main(String[] args) {

        //通过外部类的对象来实例化内部类
        //可以直接用内部类名
        B b = new A().new B();
        b.method();

    }

     class B {
        int i = 2;
        void method(){
            
            //内部类变量和外部类变量同名时，默认使用自己的
            System.out.println(i);
            
            //通过 外部类.this.变量 使用外部类的变量
            System.out.println(A.this.i);
        }
    }
}

```

其他类使用内部类
```java
public class C {
    public static void main(String[] args) {

        //需要 外部类名.内部类名 来指定
        A.B b = new A().new B();
        b.method();
    }
}
```


#### 静态内部类

用 static 修饰的内部类，可以直接调用静态变量和静态方法

```java
public class A {

    public static void main(String[] args) {

        //创建静态内部类，可以直接创建，不需要先创建外部类
        B b = new B();
        //调用静态内部类的普通方法
        b.method();
        
        //直接调用静态内部类的静态变量
        System.out.println(B.i);

        //直接调用静态内部类的静态方法
        B.methodS();

    }

    static class B {
        //静态变量
        static int i = 1;

        static void methodS(){
            System.out.println("静态内部类方法");
        }

        void method(){
            System.out.println("普通方法");
        }
    }
}
```

其他类使用当前静态内部类
```java
public class C {

    public static void main(String[] args) {

        //创建静态内部类实例
        A.B b = new A.B();
        
        b.method();
        
        System.out.println(A.B.i);
        
        A.B.methodS();
    }
}
```

#### 匿名内部类

一般用于继承其他类或者实现接口

```java
public static void main(String[] args) {

    // Thread类的匿名内部类实现
    new Thread() {
        @Override
        public void run() {
            System.out.println("重写Thread类的run方法");
        }
    }.start();

    // Runnable 接口的匿名内部类实现
    new Runnable() {
        @Override
        public void run() {
            System.out.println("重写Runnable接口的run方法");
        }
    }.run();
}
```
