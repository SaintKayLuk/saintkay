

如果一个文件中有php代码和html代码，则php代码需要在 **<?php?>** 中
```php
<?php
// php代码 
?>
//html代码
```

如果一个文件中只有php代码，则只在开头写 **<?php**
```php
<?php
// php代码 
```

## 变量

弱类型语言，变量不必声明，直接用

* 变量以 $ 符号开始，后面跟着变量的名称
* 变量名必须以字母或者下划线字符开始
* 变量名只能包含字母、数字以及下划线（A-z、0-9 和 _ ）
* 变量名不能包含空格
* 变量名是区分大小写的（$y 和 $Y 是两个不同的变量）

## 变量作用域

* local
* global
* static
* parameter
