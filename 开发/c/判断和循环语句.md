## 循环

### while语句
```c
while(condition)
{
   statement(s);
}
```

### for语句


```c
#include <stdio.h>
 
int main ()
{
   /* for 循环执行 */
   for( int a = 10; a < 20; a = a + 1 )
   {
      printf("a 的值： %d\n", a);
   }
 
   return 0;
}
```

### 无限循环

```c
  for( ; ; ){
      printf("This loop will run forever.\n");
   }
```
