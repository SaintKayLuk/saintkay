## C标准版本

* ANSI C (C89/C90)：
    ANSI C，也称为 C89 或 C90，是最早的 C 语言标准，由 ANSI 于 1989 年发布。后来，ISO 也将 ANSI C 标准化为 ISO C90。C89/C90 标准对 C 语言进行了规范化，定义了语法、标准库等内容，为 C 语言的跨平台开发奠定了基础。
* ISO C99：
    ISO C99 是 C 语言的第二个国际标准，于 1999 年发布。C99 引入了一些新的特性和改进，例如新的数据类型、内联函数、变长数组、复合字面量等。C99 标准在 C 语言的发展中起到了重要作用，为 C 语言的现代化提供了基础。
* ISO C11：
    ISO C11 是 C 语言的第三个国际标准，于 2011 年发布。C11 标准对 C 语言进行了一些改进和修订，引入了一些新的特性，如 _Generic 关键字、多线程支持、泛型宏等。C11 标准相对于 C99 标准的改变并不是那么显著，因此在实践中并没有广泛使用。
* ISO C18：
    ISO C18 是 C 语言的第四个国际标准，于 2018 年发布。C18 标准是对 C11 标准的修订和完善，主要是为了澄清一些不明确的规范和修复一些错误。C18 标准相对于 C11 标准而言并没有引入新的特性。

### 数值常量
* 前缀
0x 或 0X 表示十六进制，
0 表示八进制，
不带前缀则默认表示十进制。
```c
//十六进制
0x4b
//八进制
022
```
* 后缀，后缀是 U 和 L 的组合，没有顺序
U 表示无符号整数（unsigned）
L 表示长整数（long）
```c
//无符号整数
30u
//长整数
30l     
//无符号长整数 
30ul
```

## 存储类

存储类定义 C 程序中变量/函数的范围（可见性）和生命周期。
这些说明符放置在它们所修饰的类型之前。下面列出 C 程序中可用的存储类：

* auto
* register
* static
* extern

寄存器和RAM

寄存器位于cpu中，访问速度快
RAM相当于 内存，可用于其他类访问


### auto存储类

auto 存储类是所有局部变量默认的存储类。
auto 只能用在函数内，即 auto 只能修饰局部变量
C99 中已经被弃用，默认不写
```c
{
  int mount;
  auto int mouth;
}
```


### register 存储类

register 存储类

register关键字用于声明变量应存储在CPU的寄存器中，以提高访问速度
register关键字仅仅是一种提示，编译器可以选择忽略它
```c
{
   register int  miles;
}
```

### static存储类

用于声明静态变量，静态变量在程序的整个生命周期内存在，其生命周期与程序的运行时间相同。


* 全局静态变量：具有文件作用域，即在整个文件内可见，其他文件无法访问。
* 局部静态变量：仅在声明它的函数内可见，函数外部无法访问。

```c
//全局变量
static int count = 5;

void func( void ){
   //局部静态变量
   static int i = 5;
   i++;

   printf("i is %d and count is %d\n", i, count);
}
```


### extern存储类


extern 存储类用于提供一个全局变量的引用，全局变量对所有的程序文件都是可见的。
当您使用 'extern' 时，对于无法初始化的变量，会把变量名指向一个之前定义过的存储位置。

当您有多个文件且定义了一个可以在其他文件中使用的全局变量或函数时，可以在其他文件中使用 extern 来得到已定义的变量或函数的引用。
可以这么理解，extern 是用来在另一个文件中声明一个全局变量或函数。

file1.c
```c
#include <stdio.h>
 
int count ;
//引用file2.c文件的 write_extern() 函数
extern void write_extern();
 
main()
{
   count = 5;
   write_extern();
}
```

file2.c
```c
#include <stdio.h>
//引用file1.c文件的 count 变量
extern int count;
 
void write_extern(void)
{
   printf("count is %d\n", count);
}
```


## 运算符


杂项运算符
下表列出了 C 语言支持的其他一些重要的运算符，包括 sizeof()、&、* 和 ? :。

| 运算符   | 描述             | 实例                                 |
| -------- | ---------------- | ------------------------------------ |
| sizeof() | 返回变量的大小。 | sizeof(a) 将返回 4，其中 a 是整数。  |
| &        | 返回变量的地址。 | &a; 将给出变量的实际地址。           |
| *        | 指向一个变量。   | *a; 将指向一个变量。                 |
| ? :       | 条件表达式       | b = (a == 10) ? 20:30; <br/>如果条件为真 ? 则值为 X : 否则值为 Y |
