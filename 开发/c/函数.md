
## 函数

### 函数格式
```
return_type function_name( parameter list ){
   body of the function
}

返回值 函数名(参数列表){
  函数主体
}
```

没有返回值，则返回值设为 void

```c
void func(){
  //
}
```


### 函数声明和调用方式
函数的声明和定义可以分开，例如先声明函数名，返回值，然后下面在定义函数内部干了些什么


函数可以按顺序定义在源文件中，但函数的调用必须在调用者函数之后声明或定义被调用的函数，否则编译器将会报错
例如：
```c
#include <stdio.h>

// 提前声明函数b
void b();

void a() {
    // 在函数a中调用函数b
    b();
    printf("Inside function a\n");
}

void b() {
    printf("Inside function b\n");
}

int main() {
    a();  // 调用函数a
    return 0;
}
```
