# 网关和路由

* 路由
  * 不同网段数据转发
  * 路由选择

* 网关
  * 不同网段数据转发
  * 路由选择
  * 默认路由
  * NAT转换

查看网关
```
route -n
```

## 添加删除网关 - linux
* 临时
```
route add default gw 网关ip
route del default gw 网关ip

default是默认网关意思，即0.0.0.0 
```
* 永久
```
/etc/sysconfig/network-scripts/ifcfg-eth0
```
## 添加删除网关 - windows

```sh
#查看路由
route print
```

* 临时
```sh
#添加一条到 123.123.123.123/32 的路由，从网关123.123.123.1 出
route ADD 123.123.123.123 MASK 255.255.255.255  123.123.123.1
```

* 永久
```sh
route ADD 123.123.123.123 MASK 255.255.255.255  123.123.123.1 -p
```

# 常见命令

## ifconfig

```
ifconfig            查看网卡
ifconfig eth0 down  关闭eth0网卡
ifconfig eth1 up    开启eth1网卡

```

## route

路由操作
```sh
#查看路由表，以数字形式显示ip
route -n

#添加一条路由，访问1.1.1.1从网卡eno2出，并以2.2.2.2为网关
route add -host 1.1.1.1 gw 2.2.2.2 dev eno2
```

添加永久路由
```sh
#写入新文件，文件名为 route-网卡名，例如网卡名为eno2，则文件名为 route-eno2
#添加一条到1.1.1.1地址从网卡eno2出并以2.2.2.2为网关的路由
#删除ifcfg-eno2文件中的网关设置
echo "1.1.1.1 via 2.2.2.2 dev eno2" >> route-eno2

```

## ethtool

```sh
#查看网卡对应的网线口，例如查看eno1的网卡对应的哪个网线口，会闪烁
ethtool -p eno1

```

## netstat
查看系统的网络连接状态，路由信息，接口等
```
netstat
    -a      所有网络状态，包括socket
    -c 秒数 每隔几秒刷新一次网络状态      例：netstat -c 5  
    -n      使用ip地址和端口号显示，不使用域名和服务名
    -p      显示pid和程序名
    -t      显示tcp协议端口得连接状况
    -u      显示udp协议端口得连接状况
    -l      仅显示监听状态得连接
    -r      显示路由表
```

## traceroute
测试从当前主机目的主机之间经过的网络节点数，用于追踪数据包在网络上传输的全部路径，默认发送数据包大小是40字节，默认使用ICMP协议
```
traceroute ip/域名
  -p    使用UDP端口进行测试，默认端口为33434
  -q 3  指定测试时候发送的数据包个数，即测试次数，默认为3
  -n    以IP的方式进行连接测试，避开DNS的解析
```

## ping 
测试网络连通性
```
ping ip/域名
  -i    指定间隔时间
  -c    指定ping的次数
  -s    指定数据包的大小
```

## nmap
网络探测扫描命令

安装nmap
```
rpm -vhU https://nmap.org/dist/nmap-7.70-1.x86_64.rpm
```

```
nmap 
  -sP 网段    探测某网段内有哪些主机是存活的
  -sT ip/域名 探测某主机上开启了哪些TCP端口
```
例：查看192.168.1.1/24网段内有哪些主机在线
```
[root@localhost ~]# namp -sP 192.168.1.1/24
```
例：查看baidu.com开启了哪些tcp端口
```
[root@localhost ~]# nmap -sT baidu.com
...
PORT    STATE SERVICE
80/tcp  open  http
443/tcp open  https

STATE     端口状态
  open                该端口开放
  closed              该端口关闭
  filtered            被过滤的，由于报文无法到达指定的端口，nmap不能够决定端口的开放状态
  unfiltered          未被过滤的
  open|filtered       开放或者被过滤的
  closed|filtered     关闭或者被过滤的
```
