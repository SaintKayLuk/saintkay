## 安装域控


#### 第一步：基础配置
1. 设置固定IP，dns先填自己（127.0.0.1 或本机IP）
2. 修改计算机名，例如 DC01 重启
3. 设置 时区 & 时间
4. 关闭不必要防火墙


#### 第二步：安装 AD DS 角色

1. 打开“服务器管理器”，点左上角“管理” → “添加角色和功能”
2. 安装向导中依次选择：
3. 安装类型：基于角色或功能的安装
4. 服务器选择：选择本地服务器
5. 角色选择：勾选 ✅
6. 勾选 ”Active Directory 域服务”
7. 勾选 “DNS 服务器”
8. 一路“下一步” → “安装”

#### 第三步：提升为域控制器
1. 安装完 AD DS 后，服务器管理器右上角会出现黄色感叹号，点击“将此服务器提升为域控制器”。
2. 提升配置填写：
3. 选择：新建林
4. 根域名：比如 corp.xxx.com **(根域名全小写，计算机名大写，例如 DC01.corp.xxx.com)**
5. 功能级别：
   1. Forest：Windows Server 2016（默认即可）
   2. Domain：Windows Server 2016
   3. DNS Server ✔
   4. Global Catalog ✔
6. 设置 DSRM 密码（目录服务恢复模式密码）
7. 点击“安装”并重启


#### 验证一下

```
echo %USERDOMAIN%
返回
CORP
```

```
dnsmgmt.msc
```
查看是否存在 corp.xxx.com


## 配置DNS


配置 Forwarder ，配置上游DNS，例如8.8.8.8

条件转发（Conditional Forwarder），需要访问特定的域名走 这个dns，一般是其他内网的
