# DFS 分布式文件系统

Distributed File System（分布式文件系统）

它在 Windows Server 里主要包含两个部分：

* DFS Namespace（命名空间）
* DFS Replication（数据复制）





### DFS Namespace

创建统一路径，也就是一个入口，后面分多台文件服务器

例如：只要访问
```
\\domain.local\Files
```
实际根据dfs创建的命名空间服务器，会自动分发，并且根据文件夹，会自动找到对应的共享目录
例如：
```
IT   → fs01
HR   → fs02
Finance → fs01
```

### DFS Replication

DFS 管理页面，创建复制组即可


### 安装步骤


**需要加入域控**

再安装 角色和功能

1. 存储服务（默认安装）
2. DFS 复制
3. DFS 命名空间
4. 文件服务器资源管理器（可选，用于配额）

创建共享文件夹，**共享名后缀加上 $ 默认隐藏，只通过dfs访问**
```
服务器管理器 - 文件和存储服务 - 共享 - 右键新建共享 - SMB共享-快速 ↩︎
输入自定义路径(选择要共享的目录) - 共享名 设置为 xxx$ - 勾选"启用基于存取的枚举" - 自定义权限
```
如果一台服务器里有多个文件夹需要共享，也就是 DFS 里有多个命名空间时，则可以 在 服务器管理里只共享一个最外面的文件夹，例如 共享 **E:\\\\Share**，然后子文件夹需要单独共享并设置不同权限时在 dfs里设置就行



打开 DFS Management

新建命名空间，选择服务器，可以随便选，但是建议选文件存储这台，多台文件存储都可以添加为命名空间服务器

1. 新建命名空间，
2. 服务器选本机，文件存储这台
3. 命名空间名字，即 域名后缀，例如设置Files 则dfs 路径为 \\\domain.local\files
4. 默认选择基于域的命名空间
5. 右键新创建的命名空间，新建文件夹，
6. 名称可以设置为和原文件夹一样，但是此时不需要加 $ 后缀
7. 添加文件夹目标，选择本服务器上已经共享的文件夹，勾选之后，修改路径为ip，例如 \\\FILE01\共享文件夹$ 改为 \\\192.168.1.123\共享文件夹


ABE 设置
1. 右键命名空间-属性-高级-勾选"对此命名空间启用基于存取的枚举"
2. 右键文件夹-属性-高级- 勾选"在DFS文件夹上设置显式查看权限" - 手动配置一下



### 其他优化项

#### 配额

服务器管理器-工具-文件服务器资源管理器-配额管理

#### 显式查看权限

指定 DFS 命名空间如何控制可以查看此文件夹的用户，默认情况下从命名空间服务器的本地文件系统继承权限，并授予所有域用户查看此命名空间中全部我呢见的能能力


设置 **在 DFS 文件夹上设置显式查看权限**

此操作，默认不会加administrator 的权限，如果需要则需要手动添加进去


#### 自动映射网络驱动器

1. 登录域控服务器
2. 打开 组策略管理

```
服务器管理器
→ 工具
→ 组策略管理
→ 找到当前的域
→ 右键 "在此域中创建 GPO，并在此处链接" → 名称可以写 "自动映射网络驱动器"
```

```
右键编辑此GPO
→ 用户配置
 → 首选项
  → Windows 设置
   → 驱动器映射
新建
 → 映射驱动器
 操作 → 新建
 位置 → 填写 DFS namespace 的路径，例如 \\domain.local\files
 勾选标记为 → 文件共享
 驱动器号 → 使用 "Z"
```

#### 多路径下权限分配


示例：

文件夹的 ntfs 权限只分配给组，则 **张三** 不是 **信息管理部** 成员，需要访问 信息管理部 共享文件夹下的 部门内工作/绩效考核 这个文件夹时，只读操作，需要单独设置权限，

**最终效果：**
1. 能进入信息管理部 共享文件夹
2. 并且只能看到 部门内工作 文件夹
3. 进入部门内工作 文件夹之后只能看到 绩效考核文件夹
4. 进入绩效考核 文件夹之后能看到当前目录下所有内容


**具体操作：**

1. 域控下操作，
   1. 找到对应的 Group
   2. 新建组，DL_FS_信息管理部-部门内工作-绩效考核_RO
   3. 设置安全组 - 本地域
   4. 把张三添加到组

2. 共享服务器下操作
   1. 找到 信息管理部 和 部门内工作 两个文件夹
   2. 右键 - 属性 - 安全 - 高级
   3. 添加刚刚创建的组，应用于 **只有该文件夹**
   4. 勾选**读取和执行**，默认会勾选下面的 **列出文件夹内容** 和 **读取** 
   5. 找到 绩效考核 文件夹
   6. 右键 - 属性 - 安全
   7. 添加刚刚创建的组，编辑权限直接勾选 *读取和执行**，同样会勾选下面的 **列出文件夹内容** 和 **读取** ，不需要到高级里去操作
