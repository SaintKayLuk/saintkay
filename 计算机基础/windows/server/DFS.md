# DFS 分布式文件系统

Distributed File System（分布式文件系统）

它在 Windows Server 里主要包含两个部分：

* DFS Namespace（命名空间）
* DFS Replication（数据复制）





### DFS Namespace

创建统一路径，也就是一个入口，后面分多台文件服务器

例如：只要访问
```
\\domain.local\Files
```
实际根据dfs创建的命名空间服务器，会自动分发，并且根据文件夹，会自动找到对应的共享目录
例如：
```
IT   → fs01
HR   → fs02
Finance → fs01
```

### DFS Replication

DFS 管理页面，创建复制组即可


### 安装步骤


**需要加入域控**

再安装 角色和功能

1. 存储服务（默认安装）
2. DFS 复制
3. DFS 命名空间
4. 文件服务器资源管理器（可选，用于配额）

创建共享文件夹，**共享名后缀加上 $ 默认隐藏，只通过dfs访问**
```
服务器管理器 - 文件和存储服务 - 共享 - 右键新建共享 - SMB共享-快速 ↩︎
输入自定义路径(选择要共享的目录) - 共享名 设置为 xxx$ - 勾选"启用基于存取的枚举" - 自定义权限
```

、、、在服务器管理里，文件共享里 创建新共享，修改ntfs权限，目前还不确定这几个权限的关系



打开 DFS Management

新建命名空间，选择服务器，可以随便选，但是建议选文件存储这台，多台文件存储都可以添加为命名空间服务器

1. 新建命名空间，
2. 服务器选本机，文件存储这台
3. 命名空间名字，即 域名后缀，例如设置Files 则dfs 路径为 \\\domain.local\files
4. 默认选择基于域的命名空间
5. 右键新创建的命名空间，新建文件夹，
6. 名称可以设置为和原文件夹一样，但是此时不需要加 $ 后缀
7. 添加文件夹目标，选择本服务器上已经共享的文件夹，勾选之后，修改路径为ip，例如 \\\FILE01\共享文件夹$ 改为 \\\192.168.1.123\共享文件夹


ABE 设置
1. 右键命名空间-属性-高级-勾选"对此命名空间启用基于存取的枚举"
2. 右键文件夹-属性-高级- 勾选"在DFS文件夹上设置显式查看权限" - 手动配置一下



### 其他优化项

#### 配额

服务器管理器-工具-文件服务器资源管理器-配额管理

#### 自动映射网络驱动器

1. 登录域控服务器
2. 打开 组策略管理

```
服务器管理器
→ 工具
→ 组策略管理
→ 找到当前的域
→ 右键 "在此域中创建 GPO，并在此处链接" → 名称可以写 "自动映射网络驱动器"
```

```
右键编辑此GPO
→ 用户配置
 → 首选项
  → Windows 设置
   → 驱动器映射
新建
 → 映射驱动器
 操作 → 新建
 位置 → 填写 DFS namespace 的路径，例如 \\domain.local\files
 勾选标记为 → 文件共享
 驱动器号 → 使用 "Z"
```
