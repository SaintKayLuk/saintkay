## 共享文件夹的权限



Windows 文件共享权限 = 两层同时生效：

1️⃣ 共享权限（Share Permissions）
2️⃣ NTFS权限（安全权限 / Security）

最终生效的是：最严格的那个权限


正常我们配置

| 权限层   | 怎么配                    |
| -------- | ------------------------- |
| 共享权限 | 放开（Everyone 完全控制） |
| NTFS权限 | 精细控制（真正权限）      |


文件服务器里，共享文件一般保留
```
SYSTEM
Administrators
CREATOR OWNER
```
然后再添加 自己创建的权限组


如果要给所有认证用户，可以给 Authenticated Users


## windows 权限

* 用户（User）具体某个人。例如：
  * CORP\saintkay
  * CORP\administrator
  * FILE01\backupadmin
  * ...
* 组（Group）【最重要】企业权限核心。
  * Administrators
  * Domain Admins
  * ...
* 内置组（Built-in Groups）
    | 组                    | 作用     |
    | -------------------- | ------ |
    | Administrators       | 管理员    |
    | Users                | 普通用户   |
    | Backup Operators     | 备份权限   |
    | Remote Desktop Users | 远程桌面   |
    | Print Operators      | 打印管理   |
    | Account Operators    | 管理账户   |
    | Server Operators     | 管理服务器  |
    | DNSAdmins            | DNS管理员 |

* SYSTEM（系统身份）
  * NT AUTHORITY\SYSTEM，权限极高：SYSTEM > Administrator
* LOCAL SERVICE 本地低权限服务账户
  * NT AUTHORITY\LOCAL SERVICE
* NETWORK SERVICE
* CREATOR OWNER 动态创建者
  * 谁创建文件，谁就是 owner，常见于文件共享
* Authenticated Users 所有已认证用户，只要登录成功就属于
  * 域用户
  * 本地用户
  * 信任域用户
  * ...
* Everyone
* INTERACTIVE
* NETWORK
* ANONYMOUS LOGON
* Domain Computers 域内所有电脑
  * CORP\Domain Computers
  * 很多 GPO 针对电脑，就会用这个权限组 
* Domain Users 域用户默认组
* Domain Controllers 域控组，所有 DC 自动加入
* SELF（非常重要）
* Account Unknown（常见故障）


**全局组（Global） = 只能装本域的人，但可以去任何域用**
**域本地组（Domain Local） = 可以装任何域的人，但只能在本域用**


## 文件夹权限(NTFS权限)

```
右键 -> 属性 -> 安全
```



* 完全控制(Full Control)
* 修改
  * 读取权限
  * 写入权限
  * 删除权限
* 读取和执行
* 列出文件夹内容：只能看到目录
* 读取：不能执行
* 写入
  * 新建
  * 修改
  * 不能删除
* 特殊权限：高级共享里的自定义权限，更精细



--- 

组权限一般设置3种，而且 Windows 会自动包含下面的小权限，所以配置权限只需对应的一种

* XXX_FC 所有权：只需勾选 **完全控制**
* XXX_RW 读写权限，只需勾选 **修改**
* XXX_RO 只读权限，只需勾选 **读取和执行**
