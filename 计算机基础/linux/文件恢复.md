# linux文件恢复

两种情况
* 文件被删除，但是进程还在
* 文件被删除，进程也没有


## 进程存在

1. 查看进程id
```sh
lsof | grep xxx
```
2. 得到进程id之后，去查找进程，这步可以跳过，可以直接恢复
```sh
ll /proc/“进程id”/fd
```
3. 恢复文件，用cp复制出来即可
```
cp /proc/“进程id”/fd/1 xxx
```

## 进程不存在

1. 不要继续任何操作，先卸载挂载的文件系统
```sh
umount /xxx
```
2. 如果提示系统忙
```sh
fuser -ivk /xxx
# 再重新卸载
umount /xxx
```
3. 安装 extundelete
```sh
yum install -y extundelete
# 如果没有，则先安装
yum install -y elep-release
```
4.  查看需要恢复的文件系统的 可恢复文件，可以 一级级进去，找到需要的目录或者文件的inode，文件名等
```sh
extundelete --inode 2 /dev/xxx
```
5.  恢复指定inode
```sh
# 恢复inode值为12,13,14的文件或目录
extundelete  /dev/xxx --restore-inode 12,13,14
```
6. 恢复到当前目录下，需要重新改名，再移到自己需要的地方
