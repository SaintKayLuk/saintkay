
## sysctl 

通过sysctl 命令来查看和设置内核参数

```sh
sysctl [选项]
    -w                      临时更改某内核参数
    -p [文件/--load=文件]   重新加载内核参数，如果不指定，则从 /etc/sysctl.conf 加载
    -a                      查看所有参数
```


如果想永久设置内核参数，则把参数写入 /etc/sysctl.conf ，写入其他文件通过 sysctl -p 文件 ，重启后失效，只有写入 /etc/sysctl.conf 的参数重启不失效



#### 设置路由转发

临时开启ip4路由转发
```
echo "1" > /proc/sys/net/ipv4/ip_forward
    或
sysctl -w net.ipv4.ip_forward=1
```

永久开启ip4路由转发
```sh
echo "net.ipv4.ip_forward = 1" >> /etc/sysctl.conf
sysctl -p
```

#### 进程可以拥有的VMA(虚拟内存区域)的数量 

默认 65536
```sh
echo "vm.max_map_count = 65536" >> /etc/sysctl.conf
sysctl -p
```



## ulimit

ulimit 用于限制 shell 启动进程所占用的资源
通过ulimit临时设置，或者修改配置文件

```
ulimit [options] [limit]
    options:
        -H  设置硬限制，一旦设置不能增加
        -S  设置软限制，设置后可以增加，但是不能超过硬限制
        -a  显示当前所有limit信息
        -n  可以打开最大文件数  
        -u  最大可用进程数
    limit:
        数字，例如64，1024等
        unlimited，不限制
```

### 配置文件

```
etc/security/limits.conf
etc/security/limits.d/*.conf
```

系统先读取
etc/security/limits.d/下所有.conf结尾的文件，会覆盖etc/security/limits.conf文件

配置文件格式
```
<domain>  <type>  <item>  <value>

domain
    用户名
    组名
    通配符
    ...

type
    soft    软限制，一般不起作用，设置和硬限制一样即可
    hard    硬限制，大于等于软限制的值
    -       同时设置

item
    core 
    data
    fsize 
    nofile      打开的文件描述符的最大数量
    maxlogins   此用户最大同时登陆数，例如设置只允许一个用户登陆，则可设置此参数

```

例：设置test用户的最大文件打开数
```
cat etc/security/limits.d/test.conf

test    soft    nofile     4096
test    hard    nofile     4096
或
test    -       nofile     4096
```

某些参数需要重启生效，因为有些允许参数已经在 /proc 下，手动修改或者重启重新加载
