#### 数组定义

1. 直接定义，用 () 包裹，值用空格相隔
2. 指定下标的值，下标从0开始

例：
```sh
#定义一个长度为6的arr数组
arr=(1 2 3 4 5 abc)
#定义一个长度为4的数组，其中下标5为33，下标7为abc
arr=(1 2 [5]=33 [7]=abc)
```

#### 获取数组的值

| 格式          | 说明             |
|---------------|----------------|
| ${arr[index]} | 获取指定下标的值 |
| ${arr[@]}     | 获取数组所有值   |
| ${arr[*]}     | 获取数组所有值   |

获取不存在的下标，返回空

例：
```sh
arr=(1 2 [5]=33 [7]=abc)
#获取数组arr下标为1的值
echo ${arr[1]}
2
#获取数组arr所有值
echo ${arr[*]}
1 2 33 abc
```

#### 获取数组长度

通过${arr[@]}或者${arr[*]}将数组转化为列表再获取长度，同获取字符串长度
```sh
${#arr[@]}
${#arr[*]}
```

获取数组内某个值得长度同理
```sh
${#arr[index]}
```

例：
```sh
arr=(1 2 33 abc)
#获取数组arr长度
echo ${#arr[@]}
4
#获取数组下标为3即abc的长度
echo ${#arr[3]}
3
```

#### 数组添加修改删除

赋值数组内某个下标的值，下标不存在则添加，下标存在则修改
删除数组内值 unset arr[index]
例：
```sh
arr=(1 2 3 4 5 6 7)
#添加下标9的值123
arr[9]=123
echo ${arr[@]}
1 2 3 4 5 6 7 123
#修改下标为5的值为abc
arr[5]=abc
echo ${arr[@]}
1 2 3 4 5 abc 7 123
#删除下标为4的值
unset arr[4]
echo ${arr[@]}
1 2 3 4 abc 7 123
```

#### 数组拼接

数组拼接同字符串拼接，先获取所有数组内容，再拼接

```sh
arr_new=(${arr1[@]} ${arr2[@]})
arr_new=(${arr1[*]} ${arr2[*]})
```

可以拼接多个数组，如果两个数组中间没有空格，则前一个数组的最后一个值和后一个数组的第一个值会合并成一个值，就好比字符串
