### 字符串定义

即变量定义

例：设置变量a的值为一个字符串
```
a=abc
a="ab c"
a='a bc'
```

注意：不加双引号或者单引号的变量的值中间不能有空格

### 获取字符串长度

${#变量名}

例：获取变量a的长度
```sh
a="123456"
echo ${#a}
6
a="123 456"
echo ${#a}
7
```
注意：空格也算长度

### 字符串拼接

直接拼接，不需要任何符号

例子，将变量a和变量b拼接成变量c
```sh
c=$a$b
c="$a $b"
c="${a}abc $b"
```

建议使用双引号引起来，并且变量使用 ${} 包括起来

### 字符串截取

| 格式                   | 说明                                                                      |
|------------------------|-------------------------------------------------------------------------|
| ${string:start:length} | 从左边start数字开始截取string字符串length长度，start从0开始                |
| ${string:start}        | 从左边start数字开始截取string到末尾，start从0开始                          |
| ${string:0-end:length} | 从右边end数字开始截取string字符串length长度，end从1开始，截取也是从左到右   |
| ${string:0-end}        | 从右边end数字开始截取string字符串到末尾，end从1开始，截取也是从左到右       |
| ${string#*chars}       | 从左边开始判断遇到的第一个chars子字符串，截取chars右边的内容，不包括chars   |
| ${string##*chars}      | 从左边开始判断遇到的最后一个chars子字符串，截取chars右边的内容，不包括chars |
| ${string%chars*}       | 从右边开始判断遇到的第一个chars子字符串，截取chars左边的内容，不包括chars   |
| ${string%%chars*}      | 从右边开始判断遇到的最后一个chars子字符串，截取chars左边的内容，不包括chars |


例：截取字符串 string
```sh
string=123456789

#从左第3个数字开始截取3位
echo ${string:2:3}
345
#从右第4位开始截取3位
echo ${string:0-4:3}
678


string=123abc2323abc444
#从左开始截取遇到第一个abc子字符串的右边的内容
echo ${string#*abc}
2323abc444
#从左开始截取遇到最后一个abc子字符串的右边的内容
echo ${string##*abc}
444
#从右边开始截取遇到第一个abc子字符串的左边的内容
${string%abc*}
123abc2323
```

### 字符串替換

string=123456123456

替换首个出现的字符串
echo ${string/345/abc}
12abc6123456

替换所有字符串
echo ${string//345/abc}
12abc612abc6
