## 源码安装

* 优点
  * 开源，可修改源码   
  * 源码安装，可选择安装，安装所需功能
  * 更加稳定，效率更高
  * 卸载方便
* 缺点 
  * 编译安装，时间过长
  * 安装过程中，出现问题很难解决

```sh
#安装依赖工具等
yum -y install wget gcc gcc-c++


xxx.tar.gz                  下载源码包
tar -zxvf xxx.tar.gz        解压源码包
cd xxx                      进入解压目录
./configure                 编译前准备，作用
                              1：在安装前检测系统环境是否符合要求
                              2：定义需要的功能选项，一般使用 ./configure --prefix=安装路径 来指定安装路径
                              3：把系统环境的检测结果和定义好的功能写入Makefile文件，后续编译和安装需要依赖这个文件
make                        编译，会调用gcc编译器，并读取Makefile文件中的信息
make clean                  (可选命令)，清空 ./configura 和 make 命令产生的内容
make install                安装
```

一般未指定安装路径，会安装在 /usr/local 下
删除源码包安装，删除安装目录即可


### 源码离线安装openssh

#### 联网机器下载
```sh
yum install -y yum-utils
yumdownloader --resolve gcc make zlib-devel openssl-devel pam-devel

#下载openssl
wget https://www.openssl.org/source/openssl-1.1.1.tar.gz
#下载openssh
wget https://cdn.openbsd.org/pub/OpenBSD/OpenSSH/portable/openssh-9.8p1.tar.gz

```


#### 需要安装的机子操作

卸载原来的openssl和openssh
```sh
sudo yum remove openssl
sudo yum remove openssh
```

安装依赖包
```sh
yum localinstall *.rpm
```

先安装openssl
```sh
tar -xzf openssl-1.1.1.tar.gz
cd openssl-1.1.1
./config --prefix=/usr/local/ssl
make
make install

#编辑ld.so.conf文件
vi /etc/ld.so.conf
#添加一行
/usr/local/ssl/lib
#生效
sudo ldconfig
#设置环境变量
export PKG_CONFIG_PATH=/usr/local/ssl/lib/pkgconfig
#验证安装
/usr/local/ssl/bin/openssl version
```


安装openssh
```sh
tar -zxvf openssh-9.8p1.tar.gz
cd openssh-9.8p1
#指定 OpenSSL 和 配置文件路径
./configure --with-ssl-dir=/usr/local/ssl --sysconfdir=/usr/local/etc/ssh
make
make install
```


配置服务
```sh
sudo vi /etc/systemd/system/sshd.service

#添加如下内容
[Unit]
Description=OpenSSH server daemon
After=network.target

[Service]
ExecStart=/usr/local/sbin/sshd -D
ExecReload=/bin/kill -HUP $MAINPID
KillMode=process
Restart=on-failure

[Install]
WantedBy=multi-user.target
```
