#### 补丁

生成补丁，diff命令是比较不同，将比较内容写入文件即生成一个补丁
~~~
diff [选项] old new             比较两个文件不同
    -a  将任何文档当作文本文档处理
    -b  忽略空格造成的不同
    -B  忽略空白行造成的不同
    -I  忽略大小写造成的不同
    -N  当比较两个目录时，如果某个文件只存在于一个目录中，则在另一个目录中视为空文件
    -r  当比较目录时，递归比较子目录
    -u  使用同一的输出格式

diff [选项] old new > 补丁      将不同内容写入补丁文件  
~~~

打入补丁
~~~
patch -pn < 补丁
    n: 数字，代表补丁文件中的路径，指定更新文件的位置
~~~


### 二进制包

* 优点
  * 通过包管理，安装过程简单
  * 经过编译，安装时间比源码少
  * 经过编译，安装过程出错概率比源码小
* 缺点
  * 经过编译，不能看到源码
  * 功能选择不如源码包灵活
  * 依赖繁琐

#### RPM包(redhad系统)

##### rpm命令

rpm包命名规则

* 包全名: 安装，升级过程中(未安装的包)需要用包全名 既 xxx.rpm
* 包名: 操作已经安装的包，只需包名，例如 xxx ，如卸载rpm包：rpm -e xxx
~~~shell
a-b-c.d.e.rpm

a:      软件包命
b:      软件版本
c:      软件发布次数
d:      软件发行商
e:      适合的硬件平台
~~~



rpm包 安装，升级，需要包全名
~~~shell
rpm [选项] xxx.rpm
    -i          install,安装
    -v          显示详细信息
    -h          打印安装过程
    --nodeps    不检测依赖安装，不推荐，例如a依赖b，b依赖c，此选项仅安装a
    --force     强制安装，如果已安装，则重新安装
    --test      测试安装，不会实际安装，检测一些依赖项
    --prefix    指定安装位置，需要自己生成软连接，才能全局使用，建议安装到默认位置，不推荐

    -U(大写)    升级安装，如果没有安装，则安装，如果安装旧版本，则升级
    -F          升级安装，如果没有安装，则不安装，只有在有旧版本情况下会升级

例:安装rpm包
rpm -ivh xxx.rpm
例:升级rpm包，仅升级旧版本
rpm -Fvh xxx.rpm
~~~

卸载rpm包
~~~
rpm -e 包名
~~~
因为rpm包有依赖，安装过程中从底层开始安装，卸载过程从最高开始卸载

~~~
a依赖b，b依赖c，c依赖d
a --> b --> c --> d

安装 a.rpm 包：先安装d，再安装c，再安装b，最后安装a
卸载 a.rpm 包：直接卸载 a
卸载 c.rpm 包：先卸载 a，再卸载b，最后卸载c

如果是通过yum安装，一条指令，自动安装，卸载依赖包
安装 b.rpm ,安装d，安装c,最后安装b 
卸载 b.rpm ,卸载a，卸载b，会把所有依赖b.rpm包的所有依赖包都删除
~~~

rpm包查询，查询的是本机的rpm包
~~~
rpm -q 包名         查询本机安装的rpm包
rpm -qa 包名        查询本机所有安装的rpm包

rpm -qi 包名        查询安装的rpm包的软件信息
rpm -qip 包全名     查询本机存在的未安装的rpm包的软件信息

rpm -ql 包名        查询已安装的rpm的安装路径，所有文件路径
rpm -qlp 包全名     查询未安装的包的 默认安装位置，打算安装的位置

rpm -qf 系统文件名  查询系统文件属于哪个rpm包的，这个文件必须是rpm包安装的才能查到

rpm -qR            查询rpm包的依赖包，但是会找出所有依赖，包括linux内核，不推荐使用
~~~

验证rpm包
~~~
rpm -V  已安装包名    校验指定rpm包
    -Vf 系统文件名    校验系统文件是否被修改           
    -Va              校验所有rpm包
~~~

数字证书,先导入原厂公钥文件，安装rpm包时，验证不通过，则不允许安装并警告
~~~
数字证书目录
/etc/pki/rpm-gpg

导入数字证书
rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
~~~

RPM包中文件提取

~~~
rpm2cpio 包全名 | cpio -idv .文件绝对路径

rpm2cpio    将rpm包转换为cpio格式的命令
~~~

##### yum命令

yum源配置文件
~~~
/etc/yum.repos.d/*.repo
~~~


CentOS-Base.repo：yum默认源文件，shell注释#必须顶格写
```conf
[base]
name=CentOS-$releasever - Base
mirrorlist=http://mirrorlist.centos.org/?release=$releasever&arch=$basearch&repo=os&   infra=$infra
#baseurl=http://mirror.centos.org/centos/$releasever/os/$basearch/
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
exclude=xxx



#[base]:        容器名称，一定要放在[]中
#name:          容器说明，随便写
#mirrorlist:    镜像地址列表
#baseurl:       yum源服务器地址
#enabled：      此容器是否生效，1生效，0不生效，默认等于1
#gpgcheck:      是否开启rpm数字证书验证，1开启，0不开启 
#gpgkey:        数字证书公钥文件位置
#exclude:       不更新的包，可以使用通配符，yum更新的时候会排除这些包
```


##### mirrorlist 和 baseurl 区别

**mirrorlist**：指定了一个 URL，该 URL 返回一个包含多个镜像地址的列表。YUM 客户端会从这个列表中随机选择一个镜像来下载软件包。
**baseurl**：指定了一个单独的镜像服务器 URL。YUM 客户端会直接从这个指定的服务器下载软件包

在实际配置中，可以同时使用 mirrorlist 和 baseurl，当 mirrorlist 不可用时，可以使用 baseurl 作为备用


例:使用光盘yum源
```
创建目录，作为光盘挂载点
mkdir /mnt/cdrom
挂载光盘
mount /dev/cdrom /mnt/cdrom

修改其他yum源文件的文件名,后缀不为.repo则文件不生效
cd /etc/yum.repos.d
mv CentOS-Base.repo CentOS-Base.repo.bak 

也可以设置 enabled=0 使源不生效
...

编辑yum光盘源配置文件
vi CentOS-Media.repo

[c7-media]
name=CentOS-$releasever - Media
baseurl=file:///mnt/cdrom/    #修改为自己光盘目录
gpgcheck=1
enabled=1                     #enabled设为1，让这个yum源配置文件生效
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
```

yum命令

```sh
yum 
    list                        #查询yum源中所有软件包
    list 包名                   #查询yum源中软件包，精确查询
    list 包名 --showduplicates  #列出所有同一个包所有版本

    search 关键字               #模糊查询yum源中软件包，也可以查询某个命令在哪个包中
    provides 命令               #查询某个命令在哪个rpm包中
    deplist 包名                #查看某个包的依赖关系
    deplist 包名-version        #查询某个指定版本的包的依赖关系
    info 包名                   #查询软件包信息

    install 包名                #安装软件包
        -y                      #自动回答yes
        --downloadonly          #仅下载而不更新
        --downloaddir=dir       #指定一个其他文件夹用于保存软件包
        --force                 
        --nodeps

yum update 包名     升级软件包
    -y              自动回答yes

如果直接 yum update 后面不跟具体软件包名，会升级所有软件包，包括内核，不建议使用，必须加包命

yum remove 包名     卸载软件包


例:yum安装gcc
yum install -y gcc
```

yum源命令
```sh

yum-config-manager [选项] 资源库
    --add-repo repository_url     #添加资源库
    --enable itemName             #启用资源库 itemName就是[]中的名字
    --disable itemName            #禁用资源库
```
