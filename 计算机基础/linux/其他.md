## 占用资源

#### 占用cpu

使cpu单核或者多核使用率达到100%

* 方法一
```sh
for i in `seq 1 $(cat /proc/cpuinfo |grep processor |wc -l)`;
    do
        dd if=/dev/zero of=/dev/null & 
    done

#cat /proc/cpuinfo |grep processor |wc -l   得到cpu核心数
#seq 1 $(xxx)  生成1到$(xxx)之间的数字，即上面的到的核心数
#几个核心就循环几次，也可以直接指定循环几次
#dd if=/dev/zero of=/dev/null & 
```

* 方法二

使用 cpu_usage.sh 脚本

例：消耗 2个cpu核心
```sh
sh cpu_usage.sh consume 2
```

例：释放cpu资源
```sh
sh cpu_usage.sh release
```

#### 占用内存


* 方法一
rpm包 memload-7.0-1.r29766.x86_64.rpm
```sh
rpm -ivh memload-7.0-1.r29766.x86_64.rpm
```

占用一个G内存，单位是M，此命令会占满一颗cpu
```
memload 1024
```

例：4核8G机器占用2核4G资源，起两个进程，每个进程占用100%cpu，2g内存
```
memload 2048
memload 2048
```


开机自启，写入 /etc/rc.local 文件

```sh
memload 1024 &
memload 2048 &
```

* 方法二

使用 memory_usage.sh 脚本

例：消耗内存 1G
```sh
sh memory_usage.sh consume 1G
```
例：释放内存
```sh
sh memory_usage.sh release
```
#### 占用硬盘

1. 真实写入(速度慢)

```sh
#生成一个 1G 大小文件
dd if=/dev/zero of=1.txt bs=1G count=1

#可以用 dd 命令多次生成文件
#复制此文件
```

2. 创建空洞文件(速度块)
```sh
#创建一个 10G 大小的 test1.txt文件
fallocate -l 10G test1.txt
```



## 虚拟设备


#### /dev/null
所有输出到此的输出将被丢弃，一般把不需要的输出重定向此文件

例：执行run.sh并将输出重定向到 /dev/null，相当于丢弃
```
run.sh > /dev/null
```

#### /dev/zero

零设备，可以无限的提供空字符（0x00，ASCII代码NUL）。常用来生成一个特定大小的文件。

例：生成一个2kb大小的1.txt文件，从/dev/zero 复制到 1.txt，每次复制1024字节，复制2次
```sh
dd if=/dev/zero of=1.txt bs=1024 count=2
```


## 忘记密码

### centos7忘记密码重置

1. 启动系统进入启动选择项时按 e
2. 找到ro crashkernel…项，将ro改成rw init=/sysroot/bin/sh
3. 按 ctrl + x 按钮 进入单用户模式
4. 输入 chroot /sysroot
5. 输入 passwd root
6. 如果出现乱码输入 LANG=en，再重新输入 passwd root
7. 输入2次新密码，出现successfully成功
8. reboot



### ubuntu 忘记密码重置

1. 启动系统按 del 或者 esc 等
2. 选择 Advanced options for Ubuntu 回车进入
3. 选择当前使用的内核版本（通常选最上面的那个），按 e 进入编辑
4. 找到 linux 开头的那一行，最后的 ro 改为 rw init=/bin/bash
5. 按 Ctrl + X
6. 进入系统后重置密码 passwd root
7. 强制重启 reboot -f
