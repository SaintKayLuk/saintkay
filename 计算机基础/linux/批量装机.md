### 批量装机

#### PXE

##### 前提

关闭防火墙，selinux

##### 启动流程

```
client --> dhcp --> tftp服务器 --> pxelinux.0 --> default
                                                     ↓
   --------------------------------------------------
  ↓
vmlinxz
initrd.img
ks.cfg  -->   iso
```

1. 安装 dhcp tftp vsftp 
   * dhcp：提供ip
   * tftp：提供dhcp的下一个地址，客户机获取 pxelinux.0 等
   * vsftpd：提供整个iso
   * syslinux：提供pxelinux.0文件(有pxelinux.0文件可不装)

```sh
yum install -y dhcp vsftpd tftp tftp-server syslinux
```
2. 配置 dhcp

配置文件 /etc/dhcp/dhcpd.conf
```config
subnet 192.168.2.0 netmask 255.255.255.0 {
  range 192.168.2.111 192.168.2.222;
  next-server 192.168.2.10;
  filename "pxelinux.0";
}
```

3. 配置 tftp，vsftp

配置文件 /etc/xinetd.d/tftp
```config
service tftp
{
        socket_type             = dgram
        protocol                = udp
        wait                    = no                    #yes一台一台请求，no同时请求
        user                    = root
        server                  = /usr/sbin/in.tftpd   
        server_args             = -s /var/lib/tftpboot  #tftp根目录
        disable                 = no                    #no为启动
        per_source              = 11
        cps                     = 100 2
        flags                   = IPv4
}
```

```sh
#上传ISO到/mnt下
mkdir /mnt/centos7
mount /mnt/CentOS-7-x86_64-Minimal-1810.iso /mnt/centos7/

#镜像文件复制到 vsftp根目录
cp -r /mnt/centos7/ /var/ftp/

#必须文件复制到 tfpt 根目录

cp /mnt/centos7/isolinux/initrd.img /var/lib/tftpboot/
cp /mnt/centos7/isolinux/vmlinuz /var/lib/tftpboot/
cp /usr/share/syslinux/pxelinux.0 /var/lib/tftpboot/

mkdir /var/lib/tftpboot/pxelinux.cfg
cp /mnt/centos7/isolinux/isolinux.cfg /var/lib/tftpboot/pxelinux.cfg/default
```

default 文件修改
```
#默认选择下面的 linux 标签
default linux

...
 
#设置ks文件地址
label linux
  menu label ^Install CentOS 7
  kernel vmlinuz
  append initrd=initrd.img ks=ftp://192.168.2.10/ks.cfg
```




tftp目录结构
```
/var/lib/tftpboot

[root@localhost tftpboot]# tree 
.
├── initrd.img
├── pxelinux.0
├── pxelinux.cfg
│   └── default
└── vmlinuz
```

vsftp目录结构
```
整个iso镜像目录
ks.cfg
```

4. 启动服务
```
systemctl start dhcpd vsftpd xinetd tftp
```


5. 配置 ks 模板

```sh
#安装kickstart
yum install -y system-config-kickstart

#图形化配置ks模板
init 5

#打开终端
system-config-kickstart

#设置好参数，保存为 ks.cfg
#把 ks.cfg 文件放到ftp根目录

```
