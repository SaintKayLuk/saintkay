## linux中的硬盘


#### 硬盘接口

* IDE
* SATA
* SCSI

不同接口的硬盘在linux中显示不同
IDE接口硬盘显示为 hda，hdb，hdc等
SATA 和 SCSI 接口的硬盘都显示未 sda，sdb，sdc 等

第一块硬盘的第一个分区为 sda1

第一块硬盘的第二个分区为 sda2

以此类推...

硬盘决定了硬盘接口，一般来说主板上什么接口，那则只能使用什么接口的硬盘
有些服务器的接口有兼容，既可以使用 SATA 接口的硬盘和 SCSI 接口的硬盘
1. SATA接口一般用于 个人电脑
2. SCSI接口一般用户 服务器



#### 查看硬盘类型

```
cat /sys/block/[盘符]/queue/rotational
例：查看sda硬盘的类型，为1是机械硬盘，为0是固态硬盘
cat /sys/block/sda/queue/rotational
```
