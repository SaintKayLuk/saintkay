## netplan 



网卡配置文件在 /etc/netplan 下，如果是 00-installer-config.yaml 则需要修改ip直接修改此文件即可
```sh
/etc/netplan/00-installer-config.yaml
```

如果是 50-cloud-init.yaml ，则网卡信息是由 cloud-init 来生成的，此文件会被覆盖掉
当然也可以创建一个大于 50 开头的配置文件
 ```sh
/etc/netplan/50-cloud-init.yaml
```




修改 /etc/cloud/cloud.cfg.d/ 下的 配置文件，一般重启后或者虚拟机迁移后，netplan 下的 50-cloud-init.yaml 内容会被覆盖掉
```sh
/etc/cloud/cloud.cfg.d/05_logging.cfg
/etc/cloud/cloud.cfg.d/20-disable-cc-dpkg-grub.cfg
/etc/cloud/cloud.cfg.d/90-installer-network.cfg
/etc/cloud/cloud.cfg.d/90_dpkg.cfg
/etc/cloud/cloud.cfg.d/99-installer.cfg
```


**/etc/netplan/和/etc/cloud/cloud.cfg.d下的配置文件都会按数字大小来加载配置文件，数字大的会覆盖掉之前的配置**



## 禁用ipv6，内核层面禁用

```conf
/etc/default/grub

# 更改下面配置
GRUB_CMDLINE_LINUX="ipv6.disable=1"

# 更新 grub
update-grub
```
