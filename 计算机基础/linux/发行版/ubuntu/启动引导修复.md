## 启动修复


1. 通过u盘启动，进入“试用Ubuntu”
2. 找到原来的根分区
   ```sh
   sudo fdisl -l
   ```
3. 挂载根分区到 /mnt 
   ```sh
   sudo mount /dev/sdXY /mnt 
   # 例：根分区是 sda2
   sudo mount /deb/sda2 /mnt
   ```
4. 挂载其他路径
    ```sh
    sudo mount --bind /dev /mnt/dev
    sudo mount --bind /proc /mnt/proc
    sudo mount --bind /sys /mnt/sys
    ```
5. 切换根目录
   ```sh
   sudo chroot /mnt
   ```
6. 修复系统，并退出
   ```sh
   # 这里 sdX 只的是硬盘，不能指分区，例如 /dev/sda
   grub-install /dev/sdX
   update-grub
   exit
   ```
7. 卸载
   ```sh
   sudo umount /mnt/dev
   sudo umount /mnt/proc
   sudo umount /mnt/sys
   sudo umount /mnt
   ```
8. 重启
   ```sh
   reboot
   ```
