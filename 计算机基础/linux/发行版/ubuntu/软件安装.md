## apt
* apt：更现代化的命令，适合日常使用，推荐在交互式环境下使用。它简化了常用命令的功能，如安装、删除、更新。
  * 相当于 yum 命令
  * 它整合了 apt-get 和 apt-cache 的功能，简化了用户使用的命令，专为日常包管理任务而设计。
* apt-get：更底层、更传统的工具，适合脚本或高级用法。
* apt-cache：用于查询软件包信息。
* aptitude：用户友好，适合依赖复杂的场景，有图形界面。
* dpkg：直接操作 .deb 包，不处理依赖。，
  * 相当于rpm命令
* add-apt-repository：用于管理第三方包源。



安装包
```
apt install xxx
```

查找包
```sh
apt-cache madison gitlab-ce
```


卸载包
```sh
# 卸载包但保留配置文件
apt remove xxx
# 卸载包和配置文件等
apt purge xxx
# 自动清除有关依赖包
apt autoremove
# 清除已下载的包
apt clean
```
