# 服务器和普通台式机区别

1. 价格更高，性能更强
   1. 支持多路cpu，性能更强
   2. 支持企业SAS硬盘，转速更高，读取更快，配置阵列卡，io能力更强
   3. 单从性能来看，在一点范围之内，同样性能个人电脑比服务器便宜
2. 稳定性更高，关键配件都有冗余
   1. 可以有双电源，在一个电源损坏情况下，不会对服务器产生关机的影响
   2. 支持ecc内存条，有效保存和维持数据的完整性，同时配备校验和纠正技术，减少数据崩溃或者宕机情况
   3. 可以支持多路cpu，同时提供服务
   4. 支持服务器专用硬盘，安全性、抗震性更强
   5. 个人电脑基本没有冗余，电源或者内存条出现问题都会导致蓝屏或者重启等情况
3. 扩展性更好
   1. 支持多路cpu，主要看主板
   2. 内存插槽更多，最高内存一般都能支持到1T，主要看主板和cpu
   3. 更多的硬盘位，可支持更多硬盘
   4. 硬盘支持热插拔，在某块硬盘坏的情况下，可不关机直接替换新硬盘，自动同步数据继续服务
   5. 更多的pcie插槽
   6. 个人电脑如果需要更换硬盘，则必须拆开主机，插上电源线和sata连接线，再开机，或者在主板上插上M.2的固态 
   7. 个人电脑大部分主板不支持双cpu，支持的内存插槽和硬盘位有限

**注：电脑/服务器 性能类似水桶，性能取决于最低配置**
**注：cpu核心和线程代表能同时干多少事，频率代表干活的速度有多快**
**注：内存的容量代表能同时进行多少任务，每个进程都会占用内存容量，直到占满，频率也代表干活的速度**
**注：cpu支持的内存频率为2133hz，如果内存条频率3200hz，则向下兼容，只能发挥2133hz的速度**
