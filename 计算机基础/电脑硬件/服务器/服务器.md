### 服务器
命名规则
```
PowerEdge R750

PowerEdge： 系列
R   机架式
T   塔式
M   刀片式

750：
    第一个数字：cpu数量
        1-3是1颗cpu
        4-7是2颗cpu
        8支持2或者4颗cpu
        9是4颗cpu
    第二个数字：服务器代数，4代表14代，5代表15代
    第三个数字：0代表Intel，5代表AMD
```



## 浪潮

命名规则

```
NF 5280 M5

第一部分
    NF  机架式
    NP  塔式
第二部分
    第一个数字：cpu数量
        3   1路(1个cpu)
        5   2路(2个cpu)
        8   4路(4个cpu)
    第二个数字：厚度，1代表1U，2代表2U
    
```
