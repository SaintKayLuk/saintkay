# 版型
* E-ATX：   高性能主板，芯片组都是X字母开头，适合使用带X后缀的处理器，价格高
* ATX ：    一般大小为 305 x 244 mm，俗称大版，扩展性能好，接口全
* M-ATX：   一般大小为 244 x 244 mm，正方形的，比较好辨认，俗称小板
* ITX：     一般大小为 170 x 170 mm，小正方形，比 M-ATX 更小

版型大小
```
E-ATX > ATX > M-ATX > ITX
```

# 芯片组等级

Intel 和 AMD 处理器所用主板是不同的，也不兼容，需要根据处理器来选择主板

## Intel

Intel主板芯片组有四个等级 X > Z > B > H
同等级看第二位数字，数字越高，越高端

* X字母开头
最高级，用来搭配高端cpu，一般cpu型号后缀带有 X 字母
比如 X299 主板，可以搭配 i9-7960X 等

* Z字母开头 
次高端，Z字母开头的主板都支持超频，搭配的cpu一般带有 K 字母后缀
比如 Z370 主板，可以搭配 i5-8600K 等

* B字母开头
中端，这种主板不支持超频，主要搭配不带 K 字母后缀的cpu
比如 B365 主板，就能使用 i5-9400 或 i5-9600F 等

* H字母开头
入门级，不支持超频

## AMD

AMD主板芯片组有3个等级 X > B > A
同等级看第二位数字，和Intel一样，第二位数字越大越高端

* X字母开头
最高级，支持自适应动态扩频超频，和Intel一样，也是搭配AMD中带 X 字母后缀的处理器

* B字母开头
中端主流，支持超频，不支持完整的自适应动态扩频超频

* A字母开头
入门级，不支持超频

## 华硕

命名规则，主要分普通主板和玩家国度ROG

2013年以前用的老一套主板命名规则，2013年之后用的新的一套命名规则

新规则命名公式为 AB-C
```
A   代表芯片组名称
B   代表主板尺寸
    (空)    ATX主板
    V       具有显示输出接口的ATX主板 
    M       MATX主板
    I       ITX主板
C   代表所属系列
    Premium     高品质版
    Deluxe      豪华版
    EXPERT      专家版
    PRO         专业版
    PLUS        加强版
    A/C/E/G/K   超值版
    P/R/T/U/Y/Z 入门版
```
主板所属系列定位从高往下依次降低

例如 ausu H81M-k 就是一块h81芯片组，matx版型的超值版主板 

## 技嘉

三大系列

* Ultra Durable(超耐久系列)
* GIGABYTE Gaming 
* AORUS Gaming

命名规则 AB-C
```
A   芯片组等级
B   主板版型
    (空)    ATX版
    M       MATX版
    N/I     ITX版
C   后缀
```

#### Ultra Durable
入门级

命名规则
```
后缀
    -D              采用全固态日系电容
    -v              CPU供电简化用料
    -UD             U:超耐久            D:全固态日系电容
    -HD             H:CPU供电标准用料   D:全固态日系电容
    -SLI            支持NVIDIA SLI显卡多显卡速力
    -S数字/纯数字   代表技嘉的5个技术优化，S2代表2个技术优化，S3代表3个技术优化，以此类推
        1.  safe安全稳定
        2.  smart智能化
        3.  speed超频
        4.  silent-pipe静音热管
        5.  SLI双显
型号后缀,最后一位
    H   HDMI接口
    V   VGA接口
    p   PLUS增强版
```
例：
```
B360 HD3P   代表cpu供电标准用料，全固态日系电容，3个技术优化,plus增强版
```
